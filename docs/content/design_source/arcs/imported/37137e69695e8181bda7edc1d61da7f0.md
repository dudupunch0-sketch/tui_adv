# 01. 청류문

소유자: 두현 황

# 한 줄 정의

청류문은 정·사·마 전쟁 이후 몰락한 정파 문파다.

돈도, 인력도, 지위도, 무공 전승도 부족하지만, 남은 사람들은 서로를 버리지 않는다.

---

# 핵심 정체성

```
망한 문파
가난한 문파
정파 무림맹에게 정치질당한 문파
외문불출 무공 대부분이 소실된 문파
그러나 플레이어가 소속감을 느껴야 하는 따뜻한 홈베이스
```

청류문은 내부 고구마 갈등을 만드는 장소가 아니다.

플레이어가 “여기는 내가 지켜야 할 곳”이라고 느끼게 만드는 언더독 소속처다.

---

# 문훈

겉으로 알려진 문훈:

```
부러질지언정 구부러지지 않는다.
```

잃어버린 진짜 뜻:

```
굽히지 않는 것은 뜻이다.
몸과 방식은 흐를 수 있다.
흐르되 물들지 않는다.
굽히되 꺾이지 않는다.
```

---

# 핵심 모순

```
문파의 현재 성격:
- 구부러지지 않는 완고함

문파의 진짜 무공:
- 상대의 흐름을 보고, 받아들이고, 파훼하고, 재구성하는 유연함
```

즉 청류문은 정신적으로는 뻣뻣해졌지만, 본래 무공은 누구보다 유연한 문파다.

---

# 무공 구조

```
청류심법
- 몸 안의 기를 고정하지 않고 흐르게 하는 심법
- 상대의 기세와 흐름을 받아내기 위한 기반

청류안
- 상대의 호흡, 중심, 기의 흐름, 초식의 빈틈을 보는 눈
- 단순 동체시력이 아니라 무공 구조를 읽는 감각

관류
- 흐름을 본다

수류
- 흐름을 받아낸다

역류
- 흐름을 거슬러 끊는다

환류
- 흐름을 자기 방식으로 되돌린다
```

---

# 주인공 성장과의 연결

주인공이 다양한 기술을 익혀도 개연성이 생기는 이유:

```
청류문 무공 자체가 상대 기술의 구조를 읽는 계통이다.
천기록은 그 관찰을 현대지식 편린으로 번역해준다.
주인공은 완전한 무공을 훔치는 것이 아니라, 구조와 원리를 편린으로 복구한다.
```

성장 루프:

```
상대 기술을 본다.
↓
청류안으로 흐름을 읽는다.
↓
청류심법으로 몸 안에서 재현 가능성을 찾는다.
↓
천기록이 현대지식 후보 3개를 제시한다.
↓
플레이어가 천외편린 하나를 선택한다.
↓
소실된 청류문 무공 일부가 복구되거나 새로운 응용기가 열린다.
```

---

# 내부 갈등 정책

청류문 내부에는 고구마식 적대 갈등을 만들지 않는다.

금지:

```
내부 정치질
장로회의 고구마
주인공 지속 의심
사형제 권력 다툼
문파 내부 배신자
```

청류문의 문제는 내부 악인이 아니라 결핍이다.

```
돈 부족
인력 부족
약재 부족
소실된 비급
무너진 수련장
장문인 병상
떠난 제자의 빈 방
정파 내 지위 상실
```

---

# 갈등 원천

```
무림맹 정치질
주변 정파의 조롱과 견제
흑사방의 위협
정·사·마 전쟁의 후유증
소실된 무공
청류문 명예의 추락
```
