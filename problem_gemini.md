# Web Player UI/UX and Asset Problems

The following issues have been identified in the current Web Player implementation based on user feedback and visual analysis of the mobile screens.

## 1. Top Status & Faction UI Quality
- The status bar at the very top (displaying health, sanity, and danger) and the faction relation meters (diamond patterns) have a low-fidelity, basic appearance.
- It does not look like a polished game UI, resembling a simple form-based dashboard rather than an immersive gaming interface.

## 2. Page Scroll and Viewport Overflow
- The layout is too tall to fit within a single mobile screen (viewport), forcing the user to scroll vertically to see all content (header, story text, illustration, choice buttons, and footer tabs).
- When a page contains a lot of dialogue, text, or a large illustration, it pushes the critical choice actions below the fold.

## 3. Low-Fidelity Illustration Assets
- The current illustration representing the scene is a simple, abstract vector placeholder that lacks details, meaning, and connection to the story world, harming player immersion.
