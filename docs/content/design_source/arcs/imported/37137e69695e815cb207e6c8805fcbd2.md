# 03. 세력과 외부 압박

소유자: 두현 황

# 문서 목적

이 문서는 `이구학지 — 천기록`에서 청류문을 둘러싼 외부 세력과 압박 구조를 관리한다.

핵심 원칙은 다음과 같다.

```
외부 세력은 많이 있어도 된다.
하지만 대부분은 직접 등장하지 않고 풍문, 공문, 전서, 객잔 소문, 표국 장부, 문파 평판으로 처리한다.
```

주요 등장인물은 10명 미만으로 유지한다.

외부 세력은 세계를 넓게 보이게 만들되, 이름 있는 인물을 무작정 늘리지 않는다.

---

# 주요 세력

## 청류문

플레이어의 홈베이스.

```
망한 정파 문파
가난하지만 따뜻한 언더독 소속처
내부 고구마 갈등 금지
갈등은 외부 압박과 결핍에서 발생
```

## 흑사방

청류문을 직접 압박하는 외부 흑도 조직.

단순한 산적떼가 아니다. 보스가 사람의 약점과 빚, 두려움, 욕망을 조직력으로 바꿨기 때문에 커진 조직이다.

흑사방의 기반:

```
시장 보호비
표국 통행세
암시장 비급 거래
빚 문서
하급 관리 매수
무림맹 묵인
흑도 인력 알선
정보 거래
약점 장부
```

## 무림맹

정파의 질서와 정치적 압박을 대표한다.

```
청류문을 직접 공격하기보다, 지원 거부 / 명예 회복 지연 / 감찰 / 절차 / 공문으로 압박한다.
```

무림맹은 완전한 악이 아니라, 승자들이 질서를 관리하는 방식이다.

보스는 이 모순을 찌른다.

## 주변 정파

직접 등장보다 풍문과 태도로 처리한다.

```
비무 초청 거절
지원 거부
조롱 섞인 소문
청류문 무공을 위험하게 보는 시선
```

## 객잔 / 장터 / 표국

강호 소문과 의뢰, 미해결 부채가 드러나는 surface다.

```
객잔: 소문, 정보, 풍문 카드 출처
장터: 흑사방 압박, 미해결 부채 후일담
표국: 의뢰, 통행세, 보호비, 흑사방 압력
```

---

# 세력 표현 방식

```
직접 등장:
- 서하린
- 무명
- 흑사방 보스
- 무림맹 감찰관 또는 사자
- 객잔 주인 / 정보상

간접 등장:
- 주변 정파
- 마도 잔당
- 무림맹 상층부
- 표국 조합
- 장터 상인들
```

---

# 외부 압박 예시

```
무림맹 공문이 청류문의 지원 요청을 반려한다.
장터에서 흑사방 보호비가 오른다.
주변 정파가 청류문을 비무 초청 명단에서 제외한다.
객잔 소문에서 청류문을 “무공 훔치는 문파”라고 부른다.
표국 장부에 청류문 주변 경로가 위험 구역으로 표기된다.
```

# 체크포인트

```
- 외부 세력이 인물 수를 불필요하게 늘리지 않는가?
- 세력 압박이 공문, 풍문, 소문, 장부, 전서로 표현되는가?
- 청류문 내부에 고구마식 적대 갈등을 만들지 않는가?
- 흑사방은 단순 폭력 조직이 아니라 조직력과 약점 장악으로 커진 조직인가?
- 무림맹은 단순 악역이 아니라 정파 질서의 모순을 보여주는가?
```

# 공동파 계열 속가문파

## 최종명

```
현악문
```

## 역할

무명이 멸문시킨 문파.

공동파 본산이 아니라, 공동파의 이름과 권위를 빌려 지역에서 행세하던 외곽 속가문파다.

```
공동파 무공을 전수받았다고 주장
무림맹 하부 질서에 기대어 영향력 행사
정파의 이름을 빌려 약한 문파를 압박
청류문 몰락 이후 지역 질서를 자기 편의대로 해석
```

---

## 무공

최종명:

```
복호금쇄수
```

의미:

```
범을 굴복시키듯 상대의 관절, 기혈, 무기 흐름을 잠그는 정파식 제압술.
```

이 무공은 단순 살상 무공이 아니라, 정파가 명분을 앞세워 사람을 통제하는 폭력의 상징이다.

---

## 무명과의 연결

무명은 청류문 습격의 흔적에서 복호금쇄수 계열을 읽어낸다.

그 특별한 눈은 단순히 초식의 흐름을 보는 것이 아니라, 그 초식이 어느 계열에서 왔는지까지 읽어낸다.

이 사건은 무명의 각성과 현악문 멸문으로 이어진다.

---

## 상태

```
문파 이름: 현악문
배후 역할: 확정
무공 계열: 복호금쇄수
정파 본산과의 관계: 공동파 본산이 직접 악역이라는 뜻은 아님
```
