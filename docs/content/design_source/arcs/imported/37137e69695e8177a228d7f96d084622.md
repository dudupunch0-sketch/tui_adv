# 08. 엔딩과 후일담 연결

소유자: 두현 황

# 문서 목적

이 문서는 `이구학지 — 천기록`의 사건, 인물, 세력, 루트가 엔딩과 후일담 카드로 어떻게 연결되는지 관리한다.

---

# 기본 원칙

엔딩은 메인 결말과 후일담 카드로 나뉜다.

```
메인 엔딩:
- 귀환
- 정착
- 진실
- 장악
- 희생
- 침식
- 붕괴

후일담 카드:
- 청류문의 후일
- 서하린의 후일
- 무명의 결말
- 흑사방 보스의 결과
- 남쪽 장터의 풍문
- 천기록의 마지막 장
- 복구된 무공의 후일
- 무림맹 공문의 후일
```

---

# 후일담 출력 원칙

```
조건 충족 카드는 전부 출력한다.
모든 사건이 후일담 카드를 갖지는 않는다.
의미 있는 결과가 있는 사건만 카드화한다.
강하게 연계된 사건은 묶음 카드로 작성한다.
```

---

# 주요 연결 예시

```
청류문 재건 조건 충족
→ 청류문의 후일 카드

서하린 관계축 high
→ 서하린의 후일 카드

서하린 관계축 high + 귀환 또는 주인공 부재 계열
→ 비워둔 자리

무명 구원 성공 + 서하린 관계축 형성
→ 닫히지 않은 산문

무명 비구원 + 서하린 관계축 low
→ 마지막 밥그릇

침식 계열 + 서하린 타락 조건 충족
→ 닫힌 산문

무명 결산 조건 충족
→ 무명 운명 카드

보스 격파 또는 생존
→ 흑사방 보스 결과 카드

흑사방 잔당 미해결
→ 남쪽 장터의 풍문 카드

천기록 진실 접근
→ 천기록의 마지막 장 카드

현대 귀환 성공
→ 돌아온 출근길 / 현대 잔상 카드

청류안 오염 높음
→ 텍스트 오염 / 심마 후일담 카드
```

# 체크포인트

```
- 사건 카드가 후일담 카드로 연결되는가?
- 무명과 보스의 결말이 분리되어 있는가?
- 보스는 갱생이 아니라 결과로 처리되는가?
- 무명은 구원/비구원 양쪽이 열려 있는가?
- 미해결 부채가 플레이어를 직접 비난하지 않는가?
- 후일담은 엔딩의 부록이 아니라 핵심 보상으로 작동하는가?
```

# 카드 출력 운영 메모

```
조건 충족 카드는 전부 출력하되, suppress 규칙이 있는 경우 suppress를 우선한다.
진엔딩 계열 승리와 침식 승리 조건이 동시에 일부 충족되면, 플레이어가 사도식 계산으로 이겼는지 먼저 확인한다.
강한 증거가 있으면 무림맹의 침묵은 증거 부족이 아니라 책임 회피로 출력한다.
증거가 일부 손실되었으면 무림맹의 침묵은 사문서 처리/증거 부족 변주로 출력한다.
```

# 연결 운영 메모

```
무명 후일담은 상호 배타 그룹이 강하다.
자기 흐름 구원 계열과 검은 뱀 후계 계열은 동시에 출력하지 않는다.
전하지 못한 사과는 중간 결과 카드이므로 구원/비구원 양쪽의 일부 조건에서 조건부 출력될 수 있다.
```
