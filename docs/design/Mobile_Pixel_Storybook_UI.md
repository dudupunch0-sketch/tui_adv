# Mobile Pixel Storybook UI Contract (superseded)

Status: superseded. 2026-07-11부터 활성 Web Storybook 시각 계약은
`docs/design/Mobile_Ink_Storybook_UI.md`(수묵 서책)다.

이 문서가 정의하던 "모바일 세로형 픽셀 게임북 board" 계약과 그 기반이었던
참조 게임 스크린샷(`idea_box/플레이화면*.bmp`)은 개발 방향을 특정 상용 게임의
template에 고정시키는 문제와 저작권 문제로 폐기되었고, 해당 이미지 파일들은
저장소에서 제거되었다.

당시 계약에서 지금도 유효한 것(renderer boundary, DOM region/QA 계약,
접근성 규칙)은 전부 새 문서로 승계되었다. 이 파일은 과거 문서/커밋의 링크가
깨지지 않도록 남겨 둔 포인터다.
