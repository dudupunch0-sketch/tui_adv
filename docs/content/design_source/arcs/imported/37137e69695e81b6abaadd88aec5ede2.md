# 00. 스토리팩 관리 개요

소유자: 두현 황

# 문서 목적

이 문서는 `이구학지 — 천기록` 스토리팩의 전체 관리 구조를 정리한다.

이 스토리팩은 완성된 장편 시나리오를 한 번에 쓰는 방식이 아니라, 다음 단위를 계속 추가하고 검수하는 방식으로 운영한다.

```
사건 카드
인물 카드
세력 압박
사이드 퀘스트
천외편린 보상
메인 루트 분기
후일담 카드
엔딩 연결
```

---

# 관리 원칙

```
1. 스토리를 100% 완성하려고 하지 않는다.
2. 사건을 개별 카드로 쪼개 관리한다.
3. 각 사건은 관련 인물, 세력, 보상, 후일담, 엔딩 영향과 연결한다.
4. 주요 등장인물은 10명 미만으로 유지한다.
5. 외부 세력은 대부분 풍문, 공문, 전서, 소문으로 처리한다.
6. 청류문 내부에는 고구마식 내부 적대 갈등을 만들지 않는다.
7. 청류문은 플레이어가 소속감을 느끼는 언더독 홈베이스다.
```

# 관리 방식

이 문서군의 목적은 스토리를 길게 확정하는 것이 아니라, 각 사건을 추가·삭제·수정·검수하기 쉬운 구조를 만드는 것이다.

따라서 새로운 아이디어가 생기면 먼저 사건 카드 DB 또는 후일담 카드 DB에 카드로 추가하고, 충분히 쌓인 뒤 메인 루트 문서에 반영한다.
