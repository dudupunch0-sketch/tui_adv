## 0. 이 문서의 목적과 취급 원칙

- 사용자가 지향하는 **플레이 경험의 기준점**을 기록한다. 원본 이미지는 세로
  28,000px급이라 매번 읽기 비효율적이므로, 이 문서가 원본을 대체하는
  단일 레퍼런스다. 이후 플랜/구현 문서는 원본 이미지가 아니라 이 문서를 참조한다.
- **저작권 취급**: 타사 게임(스튜디오 윌, Life in Adventure)의 스크린샷·아트·
  본문 텍스트는 repo에 복제하지 않는다(과거 `intro-main.png` 제거 결정과 동일
  기준). 이 문서는 구조·시스템·UX 문법의 **분석 기술**만 담는다.
- 우리는 이 게임을 **베끼는 것이 아니라**, 플레이 경험의 뼈대(회차 구조,
  판정 공개, 인라인 결과 로그, 성장 루프)를 참조해 `이구학지 — 천기록`의
  수묵 세계관으로 재해석한다. 세부 내역은 추후 변경 전제.

## 1. 게임 개요

- 장르: 모바일 세로형 **회차(run) 기반 텍스트 어드벤처 RPG**. 인생게임 개발사
  스튜디오 윌 작품.
- 표면: 픽셀아트 삽화 + 양피지/고서 질감의 단일 스크롤 카드 UI.
  (우리 프로젝트는 표면을 수묵·한지로 치환 — `docs/design/Mobile_Ink_Storybook_UI.md`)
- 한 회차 = 캐릭터 생성 → 번호 붙은 이벤트 연쇄 → 성장 → 엔딩/사망 →
  점수·도감 정산 → 다음 회차. 리뷰 시점 플레이어는 248회차째였다.
  **회차 반복 자체가 콘텐츠**이며 메타 재화(보석)와 수집(도감)이 반복을 지탱한다.

## 2. 핵심 게임 루프

```text
[메인 화면: N회차 모험!]
  → 난이도 선택 (Ⅰ 모험 ~ 5단계, 클리어 시 다음 단계 해금)
  → 캐릭터 생성 (무작위=무료 / 커스텀=보석 2개)
      이름 → 성별 → 외모 → 배경 → 특성 → 능력치 분배 → 장비 프리셋
  → 배경(출신) 프롤로그 이벤트: 시작 골드/장비/특성 지급
  → [이벤트 루프]
      "모험 계속하기" → 다음 이벤트 카드
      이벤트 = 제목(선택적) + 본문 서사 + 삽화(선택적) + 선택지
      선택지 해소: 서사 진행 / 스탯 확률 판정 / 전투 / 재화 지불 확정
      결과: 〈성공〉·〈승리〉(초록 +보상) / 〈실패〉(빨강 -차감) 인라인 로그
      성장: 경험 → 레벨업(보너스 스탯 3 분배), 이벤트로 스탯 영구 증감
  → 종료: 경험 100 도달 → 엔딩 시퀀스 + 에필로그 (또는 체력 0 사망)
  → 정산: 점수 → 랭킹, 도감 갱신(몬스터/아이템/엔딩), 수집 보상 보석
  → 다음 회차 (회차 카운트 +1)
```

## 3. 화면 카탈로그

### 3.1 공통 상단 HUD (모든 인게임 화면 상시)

- 좌: 장식 프레임 초상화 + 이름패. 이름은 **특성 칭호 + 이름** 형식
  ("칼날의 브리타" → 승급 후 "검호 브리타"). 승급이 HUD에 즉시 반영된다.
- 초상 아래 자원 구슬 2줄: 체력(빨간 구슬), 정신력(청록 구슬).
  숫자가 아니라 **구슬 개수**로 표시, 빈 슬롯은 윤곽만.
- 우: 스탯 미니 패널 6칸(아이콘+숫자) — 힘(빨강)/민첩(파랑)/지능(보라)/
  카리스마(노랑)/건강(초록 하트)/지혜(남색 고리). 색·아이콘 매핑 고정.
- 우상단: 두루마리(기록/퀘스트) + 톱니(설정) 아이콘.
- 스탯 아래 금색 장식 경험치 바 — 경험 100 도달이 곧 회차 종료이므로
  이 바가 **회차 전체의 진행률 게이지**를 겸한다.

### 3.2 이벤트 화면 (게임의 기본 화면)

- 구성 순서: HUD → 덩굴 문양 구분선 → (이벤트 제목 `〈배경 이름〉`, 배경
  스토리 라인일 때) → 본문 서사 → (대형 픽셀 삽화, 중요 장면만) →
  인라인 결과 로그 → 가는 구분선 가운데 **이벤트 고유 번호** → 선택지 목록 →
  하단 글로벌 아이콘 바.
- 인라인 결과 로그 색 문법: 획득 `+ ...` 초록 / 상실 `- ...` 빨강 /
  `〈성공〉`·`〈승리〉` 초록, `〈실패〉` 빨강 / 광기·이계 대사 보라 /
  격앙 대사 강조 빨강.
- 이벤트 번호(7, 21, 52, 89, 108, 128…)는 회차 내 진행 순서가 아니라
  **이벤트 DB 식별 번호**로 보임 — 도감·수집과 연결.
- 선택지: `❖` 마름모 불릿 + 텍스트. 판정 선택지는 버튼 아래에
  **관련 스탯 아이콘 + "성공확률 : NN.N %"**를 사전 공개.
  재화 확정 선택지는 "보석 2개 소모 (현재 보석 : 62개)"처럼 잔액까지 표기.
- 선택지가 하나뿐일 때도 버튼("모험 계속하기", "여왕의 앞에 선다")으로 진행.

### 3.3 선택지의 3층 해소 구조 (골렘 수수께끼 사례)

같은 상황에 성격이 다른 해법이 병렬 제시된다:

1. **힘으로**: "닥치고 덤벼!" → 전투 돌입.
2. **판정으로**: "질문을 고민한다" → 지혜+지능 판정, 성공확률 25.9% 공개.
3. **재화로**: "정답을 알려줘" → 보석 2개 지불, 확정 성공.

실패해도 즉사가 아니라 서사가 분기한다(판정 실패 → 스탯·정신력 차감 →
"홀짝으로 문을 고른다"는 2차 도박 선택으로 이어짐). 성공 시 스탯 영구 +1,
실패 시 영구 -1인 도박형 인카운터.

### 3.4 전투 화면

- 대치 헤더: 좌 플레이어 이름+전투력(보정치 `(+0.8)` 초록), 중앙
  **승률 표시("열세 22.0 %"** 빨강 — 사전 승률 공개), 우 적 이름+전투력
  (적 보정 `(+6.5)` 빨강). 아래 HP 바 2개(초록/빨강, 수치 병기).
- 몬스터 등급 배지(예: "몬스터 등급 7")가 이벤트 텍스트 옆에 표시.
- 중앙: 픽셀 전투 장면(자동 진행). 아래 양측 버프/디버프 아이콘 열 —
  아이콘 + 스택 수, 디버프는 빨간 테두리 + 음수 표기.
- **d20 주사위**: 전투 개시 시 "주사위 굴림 (1~20)" / "굴리지 않음 (10)" /
  "전투 포기" 선택. 눈이 높을수록 아군 보정, 20이면 1레벨도 최종보스를
  이길 수 있는 수준. 재굴림은 보석 소모(멤버십은 1회 무료). 배속 버튼(`▶ x1`).
- 전투 전 이벤트 판정 실패(화살 막기 실패 등)가 승률 페널티로 이월된다.
- 승리 시: `〈승리〉 + 경험 (승리 보상) + 골드 (승리 보상) + 드랍 아이템` 로그.

### 3.5 캐릭터 생성 화면

- 항목별 "드롭다운 + 리롤(주사위) 버튼" 패턴: 이름/성별/외모/배경/특성/장비.
- 특성은 이름 앞에 붙는 접두 칭호이자 패시브(예: 날붙이류 공격력 +25%,
  힘 +4, 물리피해 -15%+막기+1 등 — 있고 없고가 유의미한 크기).
- 능력치 분배 팝업: 스탯 6종 `[-] n [+]` 스테퍼, "최대 15 / 남은 능력치가
  없어야 합니다!", 보너스 스탯 카운터, [초기화][무작위][확인].
  최저 1이지만 3 이하면 큰 패널티 → 실질 하한 4.
- 장비는 클래스 프리셋 선택(예: 파이터 = 힘·민첩 스케일 롱소드).

### 3.6 인벤토리 / 장비 / 아이템 팝업

- 장비 요약: 공격력/방어력 수치 + 장비 슬롯 행(무기/방어구/장신구,
  잠금 슬롯은 X) + 파생 스탯 줄(공속, 치명타율 15%, 치명타 피해 200%,
  회피 18%, 골드 잔액).
- 아이템 상세 팝업: 도감 번호+이름 / 분류(양손 검, 소모품, 유물…) /
  일러스트 / 어빌리티 스택 아이콘 / 피해 타입 + `(주스탯, 부스탯)` /
  가치(골드) / 플레이버 텍스트 / [사용·장착][버리기].
- 신규 무기 획득 시 **장착 중 장비와 2패널 비교 팝업**(초당공격력, 속성 분배,
  스케일링, 효과 아이콘, 가격 나란히).
- 어빌리티 스택 시스템: 장비·스탯 문턱값에서 획득, 효과 = 기본치 × 스택,
  **음수 스택(디메리트)** 존재. 예: 카운터 20%/스택, 출혈 15%/스택,
  신속함 공속 ±10%/스택. 스탯 문턱값 예: 힘·민첩 13↑ +1, 20↑ +2.

### 3.7 사망 / 기사회생

- 체력 0 → 화면 가장자리 붉은 비네트 + 사망 서사 → 선택지 2개:
  "두번만 더 기회를! (기사회생)" (보석 소모, 잔액 병기) / "영원한 안식"(런 종료).
- 부활 비용은 횟수에 따라 누진. 멤버십은 첫 회 무료.

### 3.8 메인 화면 / 메타 화면

- 메인: 양피지 카드에 "N회차 모험!" + 난이도 버튼 + [무작위 시작] +
  [모험가 커스텀(비용/면제 표기)].
- 하단 글로벌 아이콘 바 6종(전 화면 상시): 도감 / 상점 / 랭킹 / 패스 /
  모의전투 / 인벤토리.
- 도감: 몬스터(3회 전투 시 등록)·아이템·엔딩 수집 → 수집 보상으로 보석 지급,
  등록 몬스터와 모의전투 가능.
- 상점: 탭(배경/이야기/특성/꾸미기). "이야기" = 보석 50개짜리 시나리오 팩
  (1~3번은 무료 기본 제공), 구매하면 회차 안에 해당 퀘스트 라인이 등장.
- 상점 경제: 판매가는 구매가의 절반 미만. 카리스마 10마다 판매 +5%/구매 -5%.

### 3.9 설정 화면

- 언어 / 새로 시작 / BGM / 효과음 / 알림 / **다크 모드** /
  **글자 크기 스테퍼(14)** / **줄 간격 스테퍼(40)** + 라이브 미리보기 문장.
- 클라우드 세이브: [데이터 저장하기]/[데이터 불러오기] + 최근 저장 시각 +
  **"한 모험에서 3회 이상 불러오기를 하면 점수가 기록되지 않습니다!"** +
  현재 불러오기 카운터. → 세이브 스커밍(회귀 플레이)을 허용하되
  랭킹에서 배제하는 절충 설계.

### 3.10 엔딩 / 에필로그 (004번 이미지)

- 배경 스토리 라인의 최종 이벤트 → 엔딩 서사(선택지 1개짜리 페이지들) →
  결말 확정 문장("당신은 꿈꿨던 것과는 조금 다른, 위대한 모험가가 되었다").
- 에필로그 섹션: 문양 + "에필로그" 표제 후 후일담. 이후 정산(점수/도감)으로.

## 4. 시스템 카탈로그 (수치 포함)

| 시스템 | 확인된 규칙 |
|---|---|
| 스탯 6종 | 힘/민첩/지능/카리스마/건강/지혜. 생성 시 분배 상한 15, 실질 하한 4(3 이하 큰 패널티). 이벤트·소모품으로 영구 증감 |
| 스탯 문턱값 | 13/20 등 도달 시 어빌리티 단계 획득(무기 숙련: 물리 +10%, 13↑ +1, 20↑ +2) |
| 자원 | 체력·정신력을 구슬로 표시. 체력 0=사망, 정신력은 실패 페널티로 감소·포션/이벤트로 회복 |
| 판정 | 관련 스탯 아이콘 + 성공확률 % **사전 공개**. 유물 아이템(은반지)이 특정 스탯 판정 확률 보정 |
| 전투 | 자동 전투 + 사전 승률 % + d20 보정(미굴림=10 고정, 재굴림 유료, 20=사실상 필승), 전투 포기 가능 |
| 경험/레벨 | 이벤트·전투로 경험 획득(표기 예: 1/5) → 레벨업 시 보너스 스탯 3 분배. **경험 100 도달 = 회차 종료(엔딩)** |
| 성향 | 악–비도덕–중립–도덕적–선 5단계. 행동으로 증감, 히로인/선택지 개방에 영향. 선행이 후속 보은 이벤트로 연쇄(약초사→환각 사슴→정신력 회복) |
| 특성(칭호) | 생성 시 1개 + **회차당 1회 승급 이벤트**(예: 검귀 결투)로 상위 특성 교체(`- 칼날의 / + 검호`) + 전용 아이템 보상 |
| 배경 | 생성 시 선택한 출신이 프롤로그 + 회차 관통 퀘스트 라인 + 중간 분기(진영 선택)가 엔딩 결정 |
| 로맨스 | 유물(은반지) 소모 + 카리스마 판정으로 특정 NPC와 약혼/결혼, 증표 아이템 획득, 엔딩에 반영 |

## 5. 이 게임에서 추출한 UX 문법 (우리가 배울 것)

1. **정보의 정직성**: 판정 확률·승률·비용·잔액을 선택 전에 전부 공개한다.
   플레이어는 "몰라서 당하는" 일이 없고, 실패는 납득 가능한 도박의 결과다.
2. **인라인 결과 로그**: 보상/차감이 별도 팝업이 아니라 서사 본문 안에
   색 코딩된 한 줄(`+ 경험 1`, `- 지혜 1`)로 흐른다. 읽기 흐름이 끊기지 않는다.
3. **실패도 서사다**: 판정 실패가 게임오버가 아니라 다음 분기(더 나쁜 도박,
   승률 페널티 이월)로 이어진다.
4. **성장의 이중 구조**: 회차 내(스탯/레벨/장비) + 회차 간(도감/보석/해금).
   죽어도 도감·점수가 남으므로 회차가 헛되지 않다.
5. **단일 표면**: 모든 것이 "한 권의 책을 스크롤하는" 이벤트 카드 위에서
   일어나고, 상세 정보(장비/도감/설정)는 팝업·하단 바로 격리된다.
6. **칭호 = 정체성 피드백**: 특성이 이름에 붙어 HUD에 상시 노출되고,
   승급 순간 이름이 바뀌는 것이 강력한 성장 체감을 만든다.
7. **경험치 바 = 회차 진행률**: 성장 게이지와 "끝이 다가온다"는 긴장을
   하나의 바로 겸한다.
8. **텍스트 게임다운 접근성**: 글자 크기·줄 간격 조정, 다크 모드,
   라이브 미리보기.
9. **리세마라의 제도화**: 세이브/로드·재굴림·기사회생을 금지하지 않고
   비용(재화·점수 미기록)을 매겨 공식 시스템으로 흡수한다.

## 6. 우리 프로젝트 적용 노트 (채택/변형/제외 방향)

세부 확정은 coding plan(`fable_ref_step1_*.md`)에서 한다. 여기서는 방향만 기록.

### 채택 (뼈대)
- 회차 기반 루프 + 이벤트 카드 연쇄 + 이벤트 번호 표기 (기존 storypack
  구조와 정합).
- 판정 확률 사전 공개, 인라인 색 코딩 결과 로그, 실패의 서사 분기.
- 경험(회차 진행 게이지) 도달형 종료 + 에필로그 정산 — 기존
  `Wuxia_Final_State_Routing` 결산과 결합.
- 특성(칭호) + 회차당 1회 승급 이벤트 — 무협 문법(별호/경지)과 정합성이 높음.
- 도감형 수집 메타(본 엔딩/만난 인물/얻은 기록) + 회차 카운트.

### 변형
- 스탯: 기존 6스탯 설계(`Character_Stats_and_Generator.md`)와 조율.
  체력/정신력 구슬 표기는 기존 몸/마음 먹점(●◐○) 문법으로 이미 대응됨.
- d20 주사위 → 기존 2d6 판정 유지하되 "굴림의 의식화"(주사위를 보여주는
  연출)를 수묵 문법(먹점·산가지 등)으로 재해석.
- 보석(유료 재화) → 과금 없음. 메타 재화(예: 천기록 편린)로 치환하고
  기사회생·확정해소 비용으로만 사용.
- 성향 → 무협 문법의 협(俠)/마(魔) 축 등으로 재명명 검토.

### 제외
- 유료 패스/멤버십/DLC 상점, 랭킹 서버(온라인), 구글 클라우드 세이브.
- 픽셀아트 표면 전체(수묵 SVG로 대체 — 확정 사항).
- 모의전투, 상점 점원 등 주변 시스템은 후순위 백로그.
