# Illustration Assets License

The image assets in this directory are custom AI-generated works created for this project with Gemini and OpenAI image generation tools.
The July 2026 key-art refresh used user-supplied screenshots as visual references for mood, lighting, scale, environment, and motion only. No supplied screenshot is redistributed as a project asset, and generated scenes must not reproduce a recognizable character, emblem, location, or exact composition from a reference.

Spec: WebP format, <=150KB size limit, 5:3 aspect ratio (title_hero is 3:5).
Art Policy: The protagonist may appear in modern office clothing when that contrast is narratively important, but their face stays hidden or visually minimized. Wuxia characters, environments, and effects must remain original to this project.
