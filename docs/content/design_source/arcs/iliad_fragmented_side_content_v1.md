## 설계 경계와 모티브 분석표

모든 항목은 객패귀로와 완전히 독립한 범용 지역·일회 NPC·독립 세력으로 진입한다. 천기록·서하린·청류문·객패귀로·혈월교·흑사방·사도, 메인 플래그와 트루엔딩을 읽거나 쓰지 않는다. 트로이 구도와 원전 고유명은 복제하지 않는다.

## 메인 장간 스케줄·연재 계약

이 문서는 범용 [장간 교차형 사이드 콘텐츠 저작 계약](../contracts/interleaved_side_content_authoring.md)의 **first conforming example**이다. 아래 규칙은 이 사례만 읽어도 저작·검수할 수 있도록 자체 완결 형태로 유지한다.

이 콘텐츠는 메인 스토리의 각 장 사이에 끼어드는 독립 연재물이다. 기본 기대값은 메인 1장이 끝난 뒤 활성 SQ 1~2개의 현재 장과 RI 약 7개를 섞어 재생한 다음 다음 메인 장으로 넘어가는 흐름이다. scheduler는 RI와 SQ의 정확한 순서를 보장하지 않으며, 같은 SQ의 다음 장이 여러 메인 구간 뒤에 배치되는 것도 정상으로 취급한다.

- 활성 SQ: 한 메인 구간에는 서로 다른 SQ 1~2개만 활성화한다. 같은 SQ의 장을 한 구간에 두 번 배치하지 않는다.
- RI 밀도: 한 메인 구간의 기대값은 약 7개다. 플레이 시간, 지역 가용성, 중복 억제에 따라 줄거나 늘 수 있으며 정확한 개수는 완료 조건이 아니다.
- 순서 불확정: RI와 활성 SQ 장은 섞여 등장한다. SQ 장 사이에 여러 RI나 다른 SQ 장이 들어가도 의미가 이어져야 한다.
- 장간 delay: SQ의 다음 장은 인접 메인 구간에 강제하지 않는다. 메인 chapter 수가 바뀌어도 진입 범주와 anchor만으로 재배치할 수 있어야 한다.
- 독립 재진입: 각 SQ 장은 로컬 진행 변수와 durable anchor만 읽는다. 메인 플래그, 메인 인물 관계, 트루엔딩 상태를 진입 조건으로 삼지 않는다.
- 중복: 이미 완료한 SQ 장은 다시 본문을 재생하지 않는다. recap 한 줄이나 기억 파편 안내로 소비하며 다음 미완료 장의 anchor를 유지한다. RI 중복은 해당 RI의 재등장 정책에 따라 짧은 변형 대사나 보상 변형만 허용한다.
- 누락: SQ 장 하나가 scheduler에서 누락되면 다음 장을 앞당기지 않는다. 누락된 장을 다음 가용 구간에 다시 후보로 올린다. 라인 종료 전에는 순서를 건너뛰지 않는다.
- 이탈: 장 도중 이탈하거나 선택을 완료하지 못하면 그 장의 긴급 상황을 안전한 fallback state로 닫는다. 재개 시 장 처음부터 되풀이하지 않고 fallback recap과 남은 local goal부터 시작한다.
- 라인 포기: 플레이어가 SQ를 명시적으로 포기하면 현재 장을 안전하게 종료하고 후속 anchor를 비활성화한다. 지역의 소문·가격·호감도 같은 비긴급 후일 상태만 남는다.

### scheduler 예시

메인 1장 → RI → SQ01 b01 → RI → SQ03 b01 → RI 묶음 → 메인 2장 → RI → SQ01 b02 → 다른 SQ/RI → 메인 3장

위 예시는 순서 계약이 아니다. 같은 SQ의 다음 장을 바로 요구하지 않고, 각 장이 안전한 장소와 오래 남는 약속·편지·기록으로 끝난다는 점만 고정한다.

## 장 완결성 계약

SQ의 모든 beat는 하나의 독립 chapter다. chapter마다 아래 다섯 요소를 본문에 명시한다.

1. 복귀/회상: 이전 장의 핵심 선택과 현재 anchor를 1~2문장으로 되짚는다. 첫 장은 진입 소문이나 의뢰를 회상한다.
2. 해당 장 local goal: 이번 장에서 시작하고 끝낼 목표를 하나 둔다.
3. 긴급성 same-chapter closure: 전투, 추격, 운구 중 위험, 인질, 시간 제한은 이번 장 안에서 해결한다. 결과는 승패와 무관하게 안전 상태로 닫는다.
4. 종료 안정점: 인물과 물건이 머무는 안전한 장소, 부상자 치료, 유해 custody, 완료된 판정 상태를 명시한다.
5. durable next anchor: 지도, 편지, 약속, 소문, 기록, 공고, 안전한 장소에 맡긴 물건처럼 장간 delay에 견디는 연결만 사용한다.

금지 사항은 cliffhanger 전투, 노출된 시신이나 부상자 방치, 즉시 추격 요구, 다음 이벤트가 곧 발생한다는 전제, 부패·소멸하는 필수 단서다. 실패 역시 부상자 치료소 이송, 추격 종료, 봉인 관 안치, 기록 보관 같은 안전한 fallback state로 닫는다. 다음 장은 이전 긴급 상황의 계속이 아니라 그 결과를 확인하는 새 방문이나 후일 소환으로 시작한다.

| 모티브 | 무협 사건 | 의미 |
|---|---|---|
| 제사장/치유자 모욕과 역병 | 약사와 사당지기를 내쫓은 뒤 우물 열병 | 개인 모욕의 공동체 책임 |
| 공개 회의의 불편한 진실 | 조롱받는 하급 서기의 보급 누락 폭로 | 권력은 발언권을 통제한다 |
| 결투 휴전과 제3자 화살 | 결투 직전 암습 화살로 휴전 파기 | 평화는 외부 폭력에도 취약하다 |
| 환대 증표와 불공정 교환 | 선대 패물을 알아본 적수와 손해 보는 흥정 | 환대와 거래는 양가적이다 |
| 결투 뒤 선물 교환 | 적수끼리 검집과 방호패 교환 | 승패와 관계의 경계를 분리한다 |
| 야간 정찰과 포로 윤리 | 정보를 얻은 포로를 처리할지 결정 | 유용한 정보가 비열함을 면죄하지 않는다 |
| 주인을 잃은 말 | 움직이지 않는 역마의 애도 | 비인간 존재도 애도한다 |
| 전쟁과 평화의 방패 | 시장·농사·전투를 한 방패에 새김 | 공동체는 전쟁만으로 설명되지 않는다 |
| 분노한 전사와 강신/자연 반격 | 강을 더럽힌 전사에게 물살이 반격 | 자연도 반대 행위자다 |
| 분노·명예·가족·사절 | 출전 거부, 전리품, 성벽 가족, 반복 사절 | 사적 선택의 공적 비용 |
| 시신·장례·판정·연민 | 제한된 운구와 재경기 | 의례가 적대와 기억을 조정한다 |

## 보상 정본과 호감도 경계

정본 분류는 정확히 스킬, 기연, 칭호, 인물 호감도, 단체 호감도, 아이템·소모품, 퀘스트 아이템, 패물(佩物), 기억 파편이다. 등급은 보통·희귀·전설이며 수치는 provisional이다. 선택 보상은 대체로 일반 배타, 재등장 시 기억 파편 또는 미선택 방향 복기 대사로 전환한다. 인물 호감도와 단체 호감도는 메인 관계가 아니라 이 문서의 로컬 NPC·독립 세력에만 적용한다. 전설은 trade-off를 갖는다. 보상 이름은 정통 무협풍, 서정적 은유, 현대인 시선을 섞는다.

## 독립 랜덤 인카운터 20개

RI는 한 번의 이벤트에서 local goal과 immediate crisis를 모두 끝내는 3선택 독립 장면이다. 지연 결과는 소문·가격·로컬 호감도·비긴급 지역 상태만 바꾼다. SQ chapter나 메인 사건의 필수 단서, 다음 전투·추격·타이머를 RI에 숨기지 않는다. 다른 콘텐츠와 연계되더라도 bonus recap, 대사, 보상 변형만 허용한다.

### 대화형 5개

#### wuxia_iliad_random_01_pestilence_at_the_well
- 제목/유형: 쫓겨난 약사 / 대화형
- 조건: 역참 우물에 열병 소문이 돌 때 1회.
- 상황: 모욕받은 약사가 떠난 뒤 우물 이용자들이 열병 증세를 보인다. 환자 격리와 수원 폐쇄를 이번 장에서 끝내야 한다.
- 선택지: ① 관리의 공개 사과와 약사 복귀 ② 관리 체면을 남긴 채 비공개 치료 계약 ③ 약사와 함께 우물·약방 원인 조사.
- 즉시 결과: ① 환자를 치료소에 들이고 우물을 봉쇄한다 ② 약사를 중립 진료소에 머물게 하고 환자를 이송한다 ③ 오염원을 가려 폐기하고 남은 환자를 치료소에 인계한다. 어느 선택이든 열병의 즉시 확산은 이 장에서 멈춘다.
- 지연 결과: 약재 가격, 역참 약방의 로컬 단체 호감도, 관리의 평판만 달라진다.
- 보상: ① 단체 호감도 역참 약방(희귀) ② 패물(佩物) 약사패(보통) ③ 기연 열병 앞의 사과(희귀). 일반 배타.
- 종료 안정점: 환자는 진료소, 약사는 약방 또는 중립 진료소, 우물은 검사 완료 전까지 봉인 상태다.
- 재등장/후속 허용: 10회 이동 뒤 회복 소문이나 약값 변형만 허용한다. 환자 구조나 치료를 다시 요구하지 않는다.
- 플래그/원전/의미: iliad_local_01_pestilence. Book 1. 치유자를 모욕한 체면이 공동체의 병이 된다.

#### wuxia_iliad_random_02_public_council_voice
- 제목/유형: 웃음 속의 보급 장부 / 대화형
- 조건: 공개 시장 회의가 열릴 때 1회.
- 상황: 하급 서기가 보급 누락을 폭로하지만 원로들이 출신과 말투를 조롱한다.
- 선택지: ① 서기의 발언을 끝까지 보장 ② 원로와 비공개 검증 ③ 주민 증언을 먼저 수집.
- 즉시 결과: ① 회의록에 발언과 반론을 함께 남기고 회의를 폐회한다 ② 중립 서고에서 장부 사본을 봉인한 뒤 검증 일정을 잡는다 ③ 주민 증언을 서명본으로 묶고 서기를 안전한 숙소로 보낸다.
- 지연 결과: 원로·서기의 로컬 평판, 보급품 가격, 회의 소문만 달라진다.
- 보상: ① 칭호 웃음 뒤에 선 자(희귀) ② 퀘스트 아이템 누락 보급 장부(희귀) ③ 인물 호감도 서기 연휘(보통). 배타.
- 종료 안정점: 회의는 끝났고 장부·증언 사본은 중립 서고에 보관된다. 서기는 귀가하거나 숙소에서 보호받는다.
- 재등장/후속 허용: 회의록 낭독이나 보급 가격 변형만 허용한다. SQ와 메인의 필수 증거로 쓰지 않는다.
- 플래그/원전/의미: iliad_local_02_council_voice. Book 2. 조롱은 논박이 아니며 발언권이 진실의 속도를 정한다.

#### wuxia_iliad_random_03_hospitality_token_trade
- 제목/유형: 두 집안의 오래된 패물 / 대화형
- 조건: 국경 객잔에서 선대 패물을 확인할 때 1회.
- 상황: 적수 둘이 환대 증표를 알아보고 칼을 거두지만 교환 가격은 한쪽에 불리하다.
- 선택지: ① 증표를 근거로 교환 무효화 ② 선대의 거래를 존중 ③ 출처만 확인하고 새 가격으로 재협상.
- 즉시 결과: ① 물건을 원주인에게 돌리고 객잔이 휴전을 보증한다 ② 양쪽이 교환증에 서명하고 각자 숙소로 돌아간다 ③ 중립 객주가 새 가격을 적어 거래를 종결한다.
- 지연 결과: 두 집안의 로컬 호감도, 국경 물품 가격, 불공정 거래에 대한 소문만 남는다.
- 보상: ① 패물(佩物) 선대의 매듭패(희귀) ② 인물 호감도 객주 백련(보통) ③ 퀘스트 아이템 환대 교환증(보통). 배타.
- 종료 안정점: 무기는 객잔 창고에 잠시 맡겨지고 두 적수는 서로 다른 객실에서 밤을 보낸 뒤 별도로 출발한다.
- 재등장/후속 허용: 선대 환대의 bonus recap과 상점 가격 변형만 허용한다. 재결투를 요구하지 않는다.
- 플래그/원전/의미: iliad_local_03_guest_gift. Book 6. 환대는 평화를 열지만 거래의 공정까지 보장하지 않는다.

#### wuxia_iliad_random_04_horse_mourns
- 제목/유형: 움직이지 않는 역마 / 대화형

- 보상: ① 아이템·소모품 발목 감는 홍포(보통) ② 기연 느린 마지막 굽이(희귀, 승리를 포기하고 두 몸의 속도를 맞춘 경험) ③ 스킬 띠를 거두는 단수(보통, 거짓 승리를 짧게 제압하는 손기술). 배타.
- 종료 안정점: 주자는 치료·귀가했고 관중은 트랙 밖으로 물러났다. 우승 띠와 상금의 처분도 끝나 미결 판정이나 재경기가 없다.
- 재등장/후속 허용: 두 주자의 완주 대사와 참가비 변형만 허용한다. SQ05의 결승 북·재경기·공동 시상 선택을 반복하지 않는다.
- 플래그/원전/의미: iliad_local_19_false_win. Book 23. 잘못된 신호 뒤의 공정은 판정표보다 부상, 자진 포기, 끝까지 걷는 몸에서 드러난다.

#### wuxia_iliad_random_20_road_of_two_obligations
- 제목/유형: 절벽에 남은 두 밧줄 / 복합형
- 조건: 겨울 산길의 낡은 도르래가 멈추고 양쪽 바위턱에 두 사람이 고립됐을 때 1회.
- 상황: 성안 아이에게 약을 가져가는 의원과 적진에서 가족 편지를 품고 온 부상 전령이 서로 다른 턱에 매달려 있다. 도르래에는 한 번에 한 사람만 실을 수 있고 눈바람이 거세져, 누구를 먼저 당기든 다른 쪽은 가진 것을 태우거나 버려 몸을 지탱해야 한다.
- 선택지: ① 의원을 먼저 끌어올리고 전령에게 편지 꾸러미를 태워 손을 녹이며 기다리게 한다 ② 부상 전령을 먼저 끌어올리고 의원에게 약상자 일부를 눈 아래 버려 무게를 줄이게 한다 ③ 나루지기의 화물망을 잘라 두 안전줄로 엮어 동시에 당기되, 겨울 장사를 막고 손해를 플레이어가 떠안는다.
- 즉시 결과: ① 아이의 약은 온전히 도착하지만 전령의 가족 편지는 재가 된다 ② 전령과 편지는 살아 돌아오지만 약 일부를 잃어 의원이 값싼 대체 처방을 그 자리에서 마련한다 ③ 두 사람과 물건은 모두 구하지만 화물망과 도르래가 망가져 해당 산길은 계절 동안 폐쇄되고 플레이어 보상 일부가 배상으로 빠진다. 어느 선택이든 두 사람은 이 장 안에 구조·치료된다.
- 지연 결과: 약값, 전령·의원의 로컬 호감도, 폐쇄된 산길의 비긴급 통행 가격만 달라진다.
- 보상: ① 인물 호감도 의원 단초(보통) ② 패물(佩物) 그을린 편지끈(희귀, 약을 버리는 비용으로 사람과 편지를 지킨 흔적) ③ 스킬 쌍줄 인양법(전설, 지역 이동 할인 상실과 민간 구조 보정의 trade-off). 배타.
- 종료 안정점: 의원과 전령은 산막 치료상에 있고 아이의 처방도 대체분까지 확정된다. 끊긴 도르래는 사용 금지 표식 아래 놓여 추가 추락·구조·추격이 없다.
- 재등장/후속 허용: 약값·통행료·두 생존자의 짧은 후일 대사만 허용한다. 편지나 약을 main/SQ 필수 단서로 쓰지 않는다.
- 플래그/원전/의미: iliad_local_20_two_obligations. Books 6, 24. 가족에게 닿아야 할 것과 적에게도 돌려줘야 할 것을 동시에 구하려면 누군가의 물건·명예·생계가 실제로 줄어든다.


## 독립 서브 퀘스트 라인

모든 SQ는 로컬 변수와 durable anchor만 갱신한다. beat 하나가 플레이 가능한 chapter 하나이며, 다음 beat가 여러 메인 구간 뒤에 와도 복귀 문장과 anchor만으로 재개한다. 한 메인 구간에는 같은 SQ chapter를 두 번 배치하지 않는다.

### wuxia_iliad_side_01_the_price_of_refusal

- NPC/진입: 표국주 하문, 장부관 노경, 역참 아이 연두. 역참에서 하문이 출전을 거부한다는 소문으로 시작한다.
- 인물 욕망: 하문은 돈보다 사람들 앞에서 빼앗긴 공로와 지휘권을 되찾고 싶다. 노경은 보급 실패를 막고 싶지만 공개 사과가 관직의 붕괴로 이어질까 두려워한다. 연두는 두 사람의 체면보다 오늘 곡식이 도착하는지를 본다.
- line-level 상태: `insult_response`, `ration_cost`, `honor_proof`, `raid_priority`, `refusal_ending`, 하문·노경·주민 trust.
- 누적 변수 소비:
  - `insult_response`는 b02에서 하문이 창고에 직접 들어오는지, 노경이 주민 앞에 서는지, 연두가 플레이어를 믿는지를 바꾼다.
  - `ration_cost`는 b04에서 확보된 수레·치료 인력·주민 운송대의 수와 한 선택의 손실 강도를 바꾼다.
  - `honor_proof`는 b04에서 하문이 선두에 서는지 조언만 하는지, b05의 기본 결말이 복귀·공동대·단절 중 어디로 기우는지 결정한다.
  - `raid_priority`는 b05의 첫 장면에 살아 돌아와 발언하는 NPC와 기본 보상 계열을 바꾼다.
- 대표 신체 장면: b04의 황혼 습격. 앞선 배급과 명예 선택 때문에 달라진 인원으로 수레바퀴·방패·곡식 자루를 직접 지킨다.
- 권장 메인 장 배치 폭: 초반~중반 진입, 중후반 결산 허용.
- 최소 장간 공백: 인접 메인 구간 연속을 강제하지 않는다. 같은 메인 구간에 다음 chapter를 배치하지 않는다.
- 최대 장간 공백: 장기 지연 허용. 봉인 장부·곡물 인수표·후일 결산 소환장이 남아 있으면 후반에도 재개한다.

#### wuxia_iliad_side_01_b01_hear_the_insult
- 복귀 문장: 역참에서 표국주 하문이 공개 모욕을 당한 뒤 호송을 거부했다. 곡물을 기다리는 주민과 장부관 노경이 같은 객당에 모여 있다.
- 이번 장 목표/장면: 모욕의 정확한 말과 하문이 잃었다고 느끼는 것을 확인하고, 출전 거부를 폭력 없이 닫는다.
- 3선택과 즉시 결과: ① 노경에게 곡식 자루를 메고 하문의 구령대로 객당을 한 바퀴 돌게 한 뒤 같은 자리에서 사과하게 한다. 노경은 체면과 어깨를 잃고 하문은 지휘권이 보였다고 느낀다 ② 하문이 표국 명패를 직접 떼어 탁자에 놓고 떠나게 하며, 플레이어가 주민과 빈 수레를 밀어 대체 호송 가능성을 몸으로 시험한다. 하문은 자존을 지키지만 주민과 거리가 벌어진다 ③ 하문에게 돈 없는 연두 셋을 반나절 훈련시키고 그 솜씨를 출전 여부의 답으로 삼게 한다. 그는 모욕은 용서하지 않되 주민을 버리지 않는 제3의 태도를 드러낸다.
- 선행 변수 소비: 첫 장이므로 없음. 선택은 `insult_response=embodied_apology|walkout|teach_without_service`를 쓴다.
- 종료 안정점: 하문은 표국 숙소, 노경은 관사, 주민은 역참 안에 있다. 폭력이나 긴급 운송은 시작되지 않는다.
- 다음 anchor: 하문이 떼어 놓은 표국 명패, 연두들이 묶은 수레 매듭, 노경 어깨의 멍을 그린 짧은 목탄화 중 선택에 맞는 하나가 객당에 남는다.
- 재개 조건: 명패·수레 매듭·목탄화 중 남은 anchor를 보고 역참 사무방을 방문한다. 중도 이탈 시 사환이 대면 종료 요약을 전달한다.
- local state 변경: `insult_response=embodied_apology|walkout|teach_without_service`.

#### wuxia_iliad_side_01_b02_count_the_cost
- 복귀 문장: 이전 대면은 노경의 멍, 하문의 빈 명패, 연두의 수레 매듭 중 하나를 남기고 끝났다. 역참 사무방에는 현재 곡물 재고와 비어 가는 그릇이 함께 놓여 있다.
- 이번 장 목표/장면: 빈 그릇, 남은 자루, 망가진 수레를 직접 확인해 출전 거부의 당일 비용을 누가 몸으로 감당할지 정한다.
- 3선택과 즉시 결과: ① 플레이어와 주민이 창고 바닥의 자루를 같은 크기 그릇으로 끝까지 나눈다. 누구도 굶지 않지만 시장 몫이 줄어 역참 수입이 깎인다 ② 치료소까지 곡식 자루를 직접 메고 가 어린이·부상자 몫을 먼저 채운다. 약자는 안전하지만 줄 뒤의 상인들이 노경에게 공개 불만을 남긴다 ③ 부서진 수레바퀴를 하문식 결박으로 고쳐 가까운 창고를 왕복한다. 물량은 늘지만 플레이어와 자원한 주민이 부상 위험과 수리비를 감수한다.
- 선행 변수 소비: `insult_response=embodied_apology`면 노경이 ①의 배급 노동에 참여하고, `walkout`이면 하문이 ③의 결박법 제공을 거부해 수리비가 늘며, `teach_without_service`면 훈련받은 연두들이 ②·③의 부상 위험을 낮춘다.
- 종료 안정점: 당일 배급이 끝나고 남은 곡물은 잠긴 창고에 있다. 굶주린 대기열이나 이동 중인 호송은 남지 않는다.
- 다음 anchor: 날짜가 찍힌 배급표와 다음 장부 검토 약속.
- 재개 조건: 배급표의 검토일 이후 역참 장부실을 방문한다. 지연돼도 곡물은 창고 관리 상태다.
- local state 변경: `ration_cost=equal_bowls|care_first|cart_repair`와 참여 NPC trust.

#### wuxia_iliad_side_01_b03_the_missing_share
- 복귀 문장: 선택한 방식으로 당일 배급은 안정됐고, 하문이 예전 호송에서 끊어 먹은 멍에가 창고에서 발견됐다. 그의 공로 한 줄이 기록에서 빠졌다는 통지도 함께 왔다.
- 이번 장 목표/장면: 글 한 줄의 진위를 다투는 대신 하문이 과거 구한 수레와 사람의 흔적을 확인하고, 그가 어떤 명예를 돌려받을지 정한다.
- 3선택과 즉시 결과: ① 낡은 멍에와 끊긴 밧줄을 마당에 펼쳐 생존자들이 각자 하문에게 배운 동작을 재현한다. 공개 공로는 회복되지만 그날 죽은 표사의 유족도 상처를 다시 말한다 ② 하문에게 빠진 공로패를 건네되 그가 직접 불에 넣어 없앨지 품을지 고르게 한다. 관의 인정은 남지 않지만 그의 욕망이 선명해진다 ③ 공로를 복원하지 않은 채 연두들의 수레 결박 시험에 하문을 세운다. 그는 과거 이름 대신 현재 솜씨로 평가받는 비용을 감수한다.
- 선행 변수 소비: `ration_cost`에 따라 생존자·상인·치료소가 증언자로 달라진다. `insult_response`가 공개 사과면 ①에서 노경이 유족 앞에 서고, 퇴장이면 ②에서 하문이 공로패를 태울 가능성이 높으며, 무상 훈련이면 ③의 시험이 더 어려운 구간까지 열린다.
- 종료 안정점: 장부와 증서는 중립 서고에 있고 하문은 표국 숙소로 돌아간다. 회의 충돌은 종료된다.
- 다음 anchor: 하문이 남긴 호송 수락서 또는 거절서, 곡물 출발 예정 지도.
- 재개 조건: 출발 예정일이 지난 뒤 역참 게시판의 호송 결과 공고를 확인한다.
- local state 변경: `honor_proof=relic_reenact|burned_token|present_test`.

#### wuxia_iliad_side_01_b04_raid_at_dusk
- 복귀 문장: 하문의 호송 여부와 곡물 경로는 서면으로 확정됐다. 예정일 저녁, 역참 게시판에 호송대가 습격받았다는 긴급 공고가 붙는다.
- 이번 장 목표/장면: 현장에 도착해 습격을 같은 chapter 안에서 끝내고 사람·곡물의 최종 인수처를 확정한다.
- 3선택과 즉시 결과: ① 하문과 수레 사이를 뛰며 전면 대응하면 습격대를 물리치지만 하문이 다시 전면에 설 명분과 상처를 함께 얻는다 ② 주민 운송대와 곡식 자루로 낮은 방벽을 만들면 사람과 절반의 곡물을 지키되 시장 몫을 버린다 ③ 수레 결박을 베어 곡물을 미끼로 흩고 사람만 산비탈로 끌어올리면 전원 생존하지만 보급 손실과 하문의 분노를 감수한다.
- 선행 변수 소비: `ration_cost`가 공개 분배면 주민 방벽 인원이 늘고, 치료소 우선이면 현장 치료가 빨라지며, 수레 왕복이면 보존 가능한 곡물 수레가 하나 늘어난다. `honor_proof`가 공개 재현이면 하문이 ①을 먼저 제안하고, 공로패 소각이면 ③에 동의하며, 현재 솜씨 시험이면 연두들이 ②의 방벽을 완성한다.

- 재개 조건: 소환장을 받은 뒤 평시의 성문 회의실을 방문한다. 즉각 방어를 이어 갈 필요가 없다.

#### wuxia_iliad_side_03_b04_after_the_bell
- 복귀 문장: 야습은 그날 밤 끝났고 사람들은 치료와 피난을 마쳤다. 새벽 후일 책임 공방 소환장이 도착해 교대 실패와 가족 보호를 논의한다.

- 종료 안정점: 성문은 정규 수비·후임 수비·주민 수비 중 하나로 운영되고 가족은 안전한 거처에 있다.
- 다음 anchor: 성문 기록 초안과 서명 요청 편지.
- 재개 조건: 기록 초안이 완성됐다는 편지를 받은 뒤 낮 시간 기록실을 방문한다.

#### wuxia_iliad_side_03_b05_the_gate_record
- 복귀 문장: 성문의 향후 운영과 가족의 거처는 이미 정해졌다. 기록실은 누가 그 밤을 지켰는지 마지막 서명을 요청한다.
- 이번 장 목표/장면: 강려·가족·주민 공동 이름 중 기록의 주체를 확정한다.

- 종료 안정점: 성문 기록은 봉인되고 모든 인물의 근무·거처가 확정된다.

- 재개 조건: 완료 후 본문 재개 없음. 재방문 시 성문 기록 recap만 제공한다.

- 중도 이탈/실패 지속: 야습 chapter 이탈 시 내문 봉쇄와 경비 증원으로 전투를 끝내고 가족·부상자를 안전 시설로 보낸다. 실패는 통행료와 성문 평판에만 남는다.

- 재플레이: 교대자 조사, 야습 때 보호한 대상, 기록 서명자가 결말 문구를 바꾼다.

### wuxia_iliad_side_04_return_the_enemy_dead

- NPC/진입: 운구자 백담, 유족 연소, 사당지기 무연, 추격대장 곡진. 신원 미상의 유해를 중립 사당으로 옮겨 달라는 의뢰로 시작한다.
- 권장 메인 장 배치 폭: 중반 진입, 중후반~후반 후일 논쟁 허용.
- 최소 장간 공백: 인접 메인 구간 연속을 강제하지 않는다. 같은 메인 구간에 다음 chapter를 배치하지 않는다.
- 최대 장간 공백: 장기 지연 허용. 모든 chapter 끝에 사당·유족·봉인 관 custody와 인수증이 남으므로 후반에도 재개한다.

#### wuxia_iliad_side_04_b01_choose_the_body
- 복귀 문장: 전장 정리가 끝난 뒤 백담이 신원 미상의 유해를 발견했다. 중립 사당은 봉인 관과 인수 담당자를 이미 보내 놓았다.
- 이번 장 목표/장면: 유해를 노출 상태에서 회수해 신원 확인 전까지 안전한 custody에 둔다.
- 3선택과 즉시 결과: ① 공개 수습하면 양쪽 입회 아래 봉인 관에 넣어 사당으로 인계한다 ② 신분 표식을 감추고 수습하면 무연만 아는 별실 관에 봉인한다 ③ 현장 장례를 택하면 신원 표식은 서고에 보관하고 유해를 화장·안치한다.
- 종료 안정점: 유해는 사당 봉인 관 또는 봉안함에 있고 백담은 빈손으로 귀가한다. 노출된 시신과 운구 중 위험은 남지 않는다.
- 다음 anchor: 사당의 봉인 관 인수증과 신원 표식 탁본.
- 재개 조건: 사당이 신원 확인 요청 편지를 보낸 뒤 방문한다. 유해 보존은 사당 책임이라 시간 제한이 없다.

#### wuxia_iliad_side_04_b02_proof_of_kin
- 복귀 문장: 유해는 중립 사당의 봉인 관 또는 봉안함에 안전하게 있다. 연소가 인수증의 표식과 맞는 유족 증표를 들고 찾아왔다.
- 이번 장 목표/장면: 유족 관계를 검증하고 다음 장례까지 custody를 확정한다.
- 3선택과 즉시 결과: ① 증표를 감정하면 진위 기록을 붙여 관을 사당에 계속 보관한다 ② 연소의 기억 진술을 받으면 증언서를 봉인하고 유족 별실 custody로 옮긴다 ③ 양쪽 중립 증인을 요구하면 확인식을 끝내고 공동 봉인을 갱신한다.
- 종료 안정점: 유해는 봉인된 사당 관 또는 유족 별실 관에 있고 인수 책임자가 서명한다. 플레이어는 유해를 들고 있지 않다.
- 다음 anchor: 장례 방식 선택일이 적힌 사당 편지와 custody 영수증.
- 재개 조건: 편지의 선택일 이후 사당 회랑을 방문한다. 관은 상시 관리돼 지연에 따른 부패가 없다.

#### wuxia_iliad_side_04_b03_neutral_funeral
- 복귀 문장: 유족 관계와 봉인 관 custody는 검증됐다. 사당 편지는 공개 장례·비공개 장례·기념 봉안 중 하나를 정해 달라고 한다.
- 이번 장 목표/장면: 장례 의식을 이 chapter 안에서 마치고 유해의 최종 또는 임시 안치처를 정한다.
- 3선택과 즉시 결과: ① 사당 공개 장례를 치르면 의식을 끝내고 봉안당에 안치한다 ② 유족 비공개 장례를 택하면 가족 묘역의 봉인 묘실에 인계한다 ③ 화해 전까지 기념 봉안을 택하면 사당 지하 봉안고에 관을 보관한다.
- 종료 안정점: 의식은 끝났고 유해는 봉안당·가족 묘실·지하 봉안고 중 하나에 있다. 운구 중 상태가 없다.
- 다음 anchor: 장례 완료 기록과 훗날 예정된 봉인 관 이전 협의서.
- 재개 조건: 이전 협의서가 도착한 뒤 사당 사무방을 방문한다. 이전을 거절해도 현재 custody는 안전하다.

#### wuxia_iliad_side_04_b04_the_pursuit
- 복귀 문장: 장례는 끝났고 유해는 안전한 안치처에 있다. 훗날 봉인 관 이전 협의일에 곡진의 병력이 길을 막겠다는 통보가 왔다.
- 이번 장 목표/장면: 봉인 관 이전을 시도할 경우의 추격·대치·호송을 이 chapter 안에서 끝내고 새 custody를 확정한다.
- 3선택과 즉시 결과: ① 통행 협상하면 중립 입회 아래 이전을 끝내고 유족 인수증을 받는다 ② 공동 호송하면 짧은 습격을 제압한 뒤 관을 유족 묘실에 봉인한다 ③ 이전을 취소하고 은닉 보관하면 추적을 같은 날 끊고 관을 사당 지하 금고로 되돌린다.
- 종료 안정점: 추격과 전투는 끝났다. 유해는 유족 묘실 또는 사당 지하 금고, 부상자는 치료소에 있고 플레이어는 빈손이다.
- 다음 anchor: 며칠 뒤 연소가 보내는 복수 논쟁 편지와 최종 custody 확인서.
- 재개 조건: 편지를 받은 뒤 안전한 객당 또는 사당 회랑에서 연소를 만난다. 즉시 추격이나 호송은 없다.

#### wuxia_iliad_side_04_b05_after_the_return
- 복귀 문장: 봉인 관 이전과 추격은 그날 모두 끝났고 최종 custody 확인서도 발급됐다. 며칠 뒤 연소가 장례 이후에도 복수를 이어 갈지 묻는 편지를 보냈다.
- 이번 장 목표/장면: 유해 없이 진행되는 후일 대화에서 복수·애도·침묵의 결말을 정한다.
- 3선택과 즉시 결과: ① 복수 대상을 책임자에게 한정하면 연소가 민간 보복 금지 서약에 서명한다 ② 장례의 뜻을 말하면 양쪽 추모일을 기록한다 ③ 침묵을 지키면 편지를 봉인 서고에 맡기고 각자 떠난다.
- 종료 안정점: 유해는 기존 안전 custody에 그대로 있고 연소·백담·무연은 귀가한다. 새 전투나 추격은 열리지 않는다.
- 다음 anchor: 라인 결말 기록, 최종 custody 확인서, 선택 보상.
- 재개 조건: 완료 후 본문 재개 없음. 재방문 시 편지 recap과 장례 후일담만 제공한다.

- 중도 이탈/실패 지속: 어느 chapter에서 이탈해도 유해는 사당·유족·봉인 관 custody로 자동 인계된다. 추격 chapter 실패는 사당 지하 금고 회수로 끝나며 지역 통행료와 호감도만 달라진다.
- 결말/보상: 공동 호송 휴전(칭호 전설), 비밀 반환과 침묵(퀘스트 아이템 희귀), 장례 실패와 복수 논쟁(기연 희귀). 전설은 중립 보호와 일부 전투 보상 포기 trade-off.
- 재플레이: 증표 검증 방식, 장례 장소, 최종 custody, 편지 답변이 후일담을 바꾼다.

### wuxia_iliad_side_05_the_fair_funeral_games

- NPC/진입: 주관자 곽연, 심판 진수, 후보 하람, 유족 소명. 장례 경기 공고로 시작한다.
- 인물 욕망: 곽연은 고인의 이름을 큰 경기로 남기고 싶고, 진수는 자기 판정이 누구의 체면에도 휘지 않았음을 증명하고 싶다. 하람은 다친 몸을 숨기고서라도 고인의 후계자로 불리길 원하며, 소명은 고인이 사람을 다치게 하는 구실로 소비되지 않기를 바란다.
- line-level 상태: `memorial_rule`, `weapon_burden`, `cheat_response`, `drum_response`, `prize_memory`, `games_ending`, 네 NPC trust.
- 누적 변수 소비:
  - `memorial_rule`은 b03의 관중 반응과 허용 가능한 반칙 처리, b06의 기본 기억 주체를 바꾼다.
  - `weapon_burden`은 b03에서 하람의 숨은 부상 노출과 b04의 신체 위험·선택 비용을 바꾼다.
  - `cheat_response`는 b04에서 하람과 상대가 서로를 믿는 정도, 북소리 뒤 먼저 칼을 거두는 인물을 바꾼다.
  - `drum_response`와 `prize_memory`는 b06의 기본 결말과 보상 계열을 결정한다.
- 대표 신체 장면: b04의 쌍방패 비탈 오르기. 이른 북 뒤에도 상대의 무게를 버릴지 받칠지를 몸으로 선택한다.
- 권장 메인 장 배치 폭: 중반 진입, 중후반~후반 기록 결산 허용.
- 최소 장간 공백: 인접 메인 구간 연속을 강제하지 않는다. 같은 메인 구간에 다음 chapter를 배치하지 않는다.
- 최대 장간 공백: 장기 지연 허용. 종목별 경기 공고·판정 기록·상금 보관증이 다음 chapter를 보존한다.

#### wuxia_iliad_side_05_b01_rules_in_public
- 복귀 문장: 곽연이 이름 없는 무인의 장례 경기를 공고했다. 첫 경기일 전이라 규칙·상금·유족 뜻을 안전하게 조정할 수 있다.
- 이번 장 목표/장면: 참가자가 고인의 무거운 연습 방패를 한 번씩 들어 보고, 경기가 기억할 가치와 감수할 상처의 한계를 정한다.
- 3선택과 즉시 결과: ① 모두가 방패를 같은 거리만큼 메게 해 신분보다 버틴 몸을 기준으로 삼는다. 약한 참가자는 일찍 물러나지만 규칙은 납득된다 ② 하람에게 고인의 방패를 먼저 들게 해 후계자의 부담을 공개한다. 그는 명예를 얻지만 숨은 어깨 통증이 악화된다 ③ 소명이 방패에 붉은 끈을 묶고 끈이 풀리면 승부보다 즉시 중지를 우선하게 한다. 유족의 뜻은 강해지나 곽연은 경기 권위가 약해졌다고 느낀다.
- 선행 변수 소비: 첫 장이므로 없음. `memorial_rule=equal_burden|heir_burden|family_stop`을 쓴다.
- 종료 안정점: 경기는 시작되지 않았고 규칙·상금은 기록실과 금고에 있다.
- 다음 anchor: 첫 종목의 날짜가 적힌 경기 공고.
- 재개 조건: 공고일 이후 경기장 접수처를 방문한다. 날짜를 놓치면 보충 관람일로 재배치한다.
- local state 변경: `memorial_rule=equal_burden|heir_burden|family_stop`.

#### wuxia_iliad_side_05_b02_measure_the_weapons
- 복귀 문장: 고인의 방패를 어떤 몸과 한계로 기억할지 정했고 첫 종목 일정도 확정됐다. 경기 전날, 심판 진수가 참가자 손으로 무기의 부담을 확인해 달라고 한다.
- 이번 장 목표/장면: 숫자 측정표 대신 참가자가 무기의 무게·균형·손잡이 마찰을 몸으로 확인하고, 어떤 부담을 경기에서 인정할지 정한다.
- 3선택과 즉시 결과: ① 눈을 가린 채 서로의 무기를 세 번 들어 중심이 쏠린 것을 골라낸다. 공정성은 높지만 손목 피로가 남는다 ② 하람과 상대가 무기를 바꿔 들고 짧은 기본식을 펼친다. 장비 차이는 드러나지만 각자의 비법 한 수가 노출된다 ③ 각자 자기 무기의 흠을 공개하고 그대로 짊어진다. 검사 시간은 줄지만 흠을 숨긴 사람은 이후 보호를 잃는다.
- 선행 변수 소비: `memorial_rule=equal_burden`이면 ①의 피로가 고르게 분산되고, `heir_burden`이면 하람의 어깨 떨림이 ②에서 드러나며, `family_stop`이면 소명이 ③에서 위험 무기 하나를 직접 제외한다.
- 종료 안정점: 무기는 봉인 보관소, 선수는 숙소, 검사 기록은 서고에 있다. 경기는 아직 시작되지 않는다.
- 다음 anchor: 검사표와 다음 날 예선 공고.
- 재개 조건: 예선 공고일 이후 경기장을 방문한다. 보관소가 무기를 관리하므로 시간 제한이 없다.
- local state 변경: `weapon_burden=blind_balance|weapon_exchange|declared_flaw`.

#### wuxia_iliad_side_05_b03_catch_the_cheat
- 복귀 문장: 무기 검사는 끝났고 예선 공고가 열렸다. 하람이 규칙 밖 보조 끈을 쓴 장면을 심판과 관중이 함께 목격한다.
- 이번 장 목표/장면: 하람의 보조 끈이 속임수이면서 동시에 다친 어깨를 붙드는 도구임을 확인하고, 예선의 몸과 명예를 같은 날 닫는다.
- 3선택과 즉시 결과: ① 끈을 잘라 공개 실격시키면 상대가 진출하지만 하람의 부상과 수치가 모두 드러난다 ② 양쪽 모두 같은 보조 끈을 매고 짧은 비살상 재대결을 끝내면 조건은 같아지나 상대도 불필요한 구속을 감수한다 ③ 하람이 스스로 끈과 후계자 표식을 내려놓고 기권하게 하면 몸은 지키지만 그가 원한 이름을 잃는다.
- 선행 변수 소비: `weapon_burden`이 눈가림이면 끈의 무게 차이를 진수가 먼저 발견하고, 무기 교환이면 상대가 하람의 통증을 알아 ②에 동의하며, 흠 공개면 하람이 ③을 먼저 제안한다. `memorial_rule`은 관중이 실격·재대결·기권을 명예로 받아들이는 정도를 바꾼다.
- 종료 안정점: 예선은 실격·재경기 판정·현 결과 승인 중 하나로 닫혔다. 선수는 치료·귀가하고 무기는 보관소에 있다.
- 다음 anchor: 결승 종목 공고와 예선 판정서.
- 재개 조건: 결승 공고일 이후 방문한다. 예선 판정을 다시 해결할 필요가 없다.
- local state 변경: `cheat_response=cut_and_disqualify|equal_straps|voluntary_withdrawal`.

#### wuxia_iliad_side_05_b04_the_early_drum
- 복귀 문장: 하람의 보조 끈을 처리한 방식과 결승 종목 공고를 되짚는다. 쌍방패 비탈 결승 중 소명이 위험을 보고 북을 일찍 울린다.
- 이번 장 목표/장면: 두 선수가 쌍방패를 맞대고 비탈을 오르는 결승에서 이른 북이 울린 뒤, 미끄러진 상대를 버릴지 받칠지 선택하게 하고 그 몸의 결과로 결승을 끝낸다.
- 3선택과 즉시 결과: ① 하람에게 북을 따르게 해 손을 놓게 한다. 그는 우승 띠를 얻지만 넘어진 상대를 플레이어가 몸으로 받아 치료해야 하고 관중의 존경 일부를 잃는다 ② 북을 무시하고 두 선수의 방패 사이에 들어가 무게를 나눠 정상까지 함께 오른다. 승자는 없고 플레이어의 어깨 부상과 상금 포기가 비용이다 ③ 소명이 붉은 중지 끈을 당겨 경기를 취소하고 하람과 상대가 서로를 부축해 내려오게 한다. 유족은 비난을 감수하고 곽연의 대회 명성은 꺾인다.
- 선행 변수 소비: `weapon_burden`이 하람의 남은 어깨 힘과 ①의 부상 강도를 바꾸며, `cheat_response`가 공개 실격이면 상대가 하람을 믿지 않고, 동일 끈이면 ②를 먼저 받아들이며, 자진 기권이면 하람이 ③에서 먼저 칼을 거둔다.
- 종료 안정점: 결승 승자와 상의 소유자가 확정되고 선수는 치료·귀가한다. 미결 경기나 즉시 재경기는 없다.
- 다음 anchor: 시상식 기록과 상금 분배일 공고.
- 재개 조건: 분배일 이후 기록실을 방문한다. 결승 결과는 이미 확정 상태다.
- local state 변경: `drum_response=release_for_win|shared_climb|family_cancel`.

#### wuxia_iliad_side_05_b05_prize_and_record
- 복귀 문장: 이른 북 뒤의 결승과 부상 치료는 그날 끝났다. 별도 추모일에 고인의 방패·약재전·은띠를 어느 몸과 기억에 남길지 정한다.
- 이번 장 목표/장면: 상금인 고인의 연습 방패·약재전·은띠를 누구의 손에 남겨야 앞선 결승의 의미가 거짓말이 되지 않는지 정한다.
- 3선택과 즉시 결과: ① 결승에서 끝까지 버틴 사람에게 방패를 직접 메고 묘 앞까지 가져가게 한다. 명예는 개인에게 남지만 어깨의 책임도 따른다 ② 약재전을 다친 참가자 모두에게 쓰고 소명은 빈 상자를 집으로 가져간다. 사람은 회복하지만 눈에 보이는 우승 기념물은 사라진다 ③ 은띠를 잘라 참가자·심판·유족에게 한 토막씩 나눈다. 공동 기억은 남지만 원형 유품은 되돌릴 수 없게 훼손된다.
- 선행 변수 소비: `drum_response`가 손 놓기면 ①의 수령자는 우승자지만 상대 trust가 감소하고, 함께 오르기면 ②의 치료 범위가 넓어지며, 경기 취소면 ③을 소명이 먼저 제안한다. `cheat_response`에 따라 하람이 보상을 받을 자격을 주장하거나 스스로 물러난다.
- 종료 안정점: 상금은 수령자 또는 금고에 있고 분배 이의 기간도 종료된다.
- 다음 anchor: 최종 장례 경기 기록의 서명 요청서.
- 재개 조건: 기록 완성 통지를 받은 뒤 서고를 방문한다. 상금은 보관증으로 보호된다.
- local state 변경: `prize_memory=burden_carried|medicine_spent|relic_divided`.

#### wuxia_iliad_side_05_b06_sign_the_memory
- 복귀 문장: 모든 종목과 상금 분배가 끝났다. 소명은 경기의 주인을 어떻게 기억할지 적은 최종 기록에 서명을 요청한다.
- 이번 장 목표/장면: 빈 경기장에서 남은 방패 자국·치료 천·잘린 은띠를 바라보고, 누적 행동이 이미 만든 기억을 받아들이거나 실제 명예를 희생해 뒤집는다.
- 3선택과 즉시 결과: ① 누적 결과를 그대로 남긴다. `memorial_rule`, `drum_response`, `prize_memory`에 따라 후계자의 승리, 서로를 받친 경기, 유족이 멈춘 경기 중 하나가 기본 결말이 되고 해당 인물이 마지막 흔적을 직접 걸어 둔다 ② 기본 결말을 뒤집어 하람이 우승 띠와 후계자 호칭을 상대에게 돌려준다. 하람은 공개 명예와 보상 한 단계 상승 가능성을 잃지만 관계를 회복한다 ③ 공식 승자 이름을 남기지 않고 소명이 기록 두루마리를 찢어 참가자 각자의 몸짓 한 줄만 목판에 새긴다. 판정의 단일 권위와 경기장 후원은 줄지만 여러 기억이 남는다.
- 선행 변수 소비: `memorial_rule`과 `weapon_burden`이 ①의 기본 기억과 진수의 태도를, `cheat_response`와 `drum_response`가 하람·상대의 화해 가능성을, `prize_memory`가 마지막에 걸리는 물건과 보상 계열을 바꾼다. ②·③은 명예·후원 손실을 치르는 override다.
- 종료 안정점: 기록은 서고에 봉인되고 경기장·금고·선수 상태는 모두 정산 완료다.
- 다음 anchor: 라인 결말 기록과 선택 보상.
- 재개 조건: 완료 후 본문 재개 없음. 재방문 시 종목별 recap과 보상 변형만 제공한다.
- local state 변경: `games_ending=earned|honor_returned|many_gestures`, line closed.

- 중도 이탈/실패 지속: 경기 chapter 이탈 시 심판이 해당 종목을 중단·무효 처리하고 선수와 무기를 안전하게 돌려보낸다. 실패는 다음 경기 참가비·평판·관중 대사에만 남는다.
- 결말/보상: 누적 기억 수용은 패물(佩物) 닳은 방패끈(보통), 하람의 명예 반환은 기연 이름을 돌려준 완주(희귀, 우승 보상 포기 trade-off), 여러 몸짓의 목판은 칭호 승자 없는 추모의 증인(희귀, 경기장 할인 상실 trade-off). 배타.
- 재플레이: 고인의 방패를 든 방식, 숨은 부상을 다룬 선택, 이른 북 뒤 상대를 놓거나 받친 몸짓, 유품의 처분이 기본 기억과 결말을 바꾼다.
- 라인 대사 저작 가이드: 곽연은 관중 규모와 고인의 이름을 한 문장에 묶고, 진수는 자기 판정이 흔들릴수록 규칙 어휘가 길어진다. 하람은 아픈 어깨를 숨길 때 공격적으로 말하고, 소명은 ‘누가 이겼나’보다 ‘누가 누구를 놓았나’를 묻는다. 경기 문서는 마지막 흔적을 보존할 뿐, 사람의 선택을 대신 판정하지 않는다.
