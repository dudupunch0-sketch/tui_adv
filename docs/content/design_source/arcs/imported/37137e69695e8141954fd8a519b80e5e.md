# 06. 사이드 퀘스트와 미해결 부채

소유자: 두현 황

# 문서 목적

이 문서는 `이구학지 — 천기록`에서 사이드 퀘스트와 미해결 부채를 어떻게 관리할지 정의한다.

---

# 기존 탐색 시스템과 연결

사이드 퀘스트는 랜덤 인카운터 속에서 시작되는 연속 사건이다.

```
작은 단서:
- 여러 개 가능

활성 사이드 퀘스트:
- 최대 3개

중요 사이드 퀘스트:
- 최대 1개
```

---

# 핵심 원칙

```
중요 사이드 퀘스트를 방치해도 메인 엔딩은 막지 않는다.
대신 미해결 부채로 남아 후일담에 반영된다.
```

미해결 부채는 플레이어를 직접 비난하지 않는다.

풍문, 부재, 세계 변화, 잔상으로 보여준다.

---

# 사이드 퀘스트 후보

```
보물지도
표국 의뢰
흑사방 잔당
실종 제자
소실 비급 조각
객잔의 오래된 전서
마도 잔당 풍문
무림맹 감찰 문서
```

---

# 미해결 부채 후일담 원칙

금지:

```
네가 흑사방 잔당을 방치해서 장터가 습격당했다.
```

권장:

```
남쪽 장터에서는 흑사방 잔당이 다시 표국을 습격했다는 풍문이 돌았다.

청류문 장로들은 그것을 작은 불씨라 불렀지만,
장터 사람들은 안다.
작은 불씨는 늘 누군가가 대수롭지 않게 넘긴 자리에서 살아난다는 것을.
```

---

# 체크포인트

```
- 메인 엔딩을 막지 않는가?
- 방치 시 후일담 카드로 연결되는가?
- 직접적 인과 설명을 피하는가?
- 풍문, 부재, 세계 변화, 잔상으로 표현되는가?
- 다회차 욕구를 만드는가?
```
