## 설계 경계와 모티브 분석표

모든 항목은 객패귀로와 완전히 독립한 범용 지역·일회 NPC·독립 세력으로 진입한다. 천기록·서하린·청류문·객패귀로·혈월교·흑사방·사도, 메인 플래그와 트루엔딩을 읽거나 쓰지 않는다. 트로이 구도와 원전 고유명은 복제하지 않는다.

| 모티브 | 무협 사건 | 의미 |
|---|---|---|
| 제사장/치유자 모욕과 역병 | 약사와 사당지기를 내쫓은 뒤 우물 열병 | 개인 모욕의 공동체 책임 |
| 공개 회의의 불편한 진실 | 조롱받는 하급 서기의 보급 누락 폭로 | 권력은 발언권을 통제한다 |
| 결투 휴전과 제3자 화살 | 결투 직전 암습 화살로 휴전 파기 | 평화는 외부 폭력에도 취약하다 |
| 환대 증표와 불공정 교환 | 선대 패물을 알아본 적수와 손해 보는 흥정 | 환대와 거래는 양가적이다 |
| 결투 뒤 선물 교환 | 적수끼리 검집과 방호패 교환 | 승패와 관계의 경계를 분리한다 |
| 야간 정찰과 포로 윤리 | 정보를 얻은 포로를 처리할지 결정 | 유용한 정보가 비열함을 면죄하지 않는다 |
| 주인을 잃은 말 | 움직이지 않는 역마의 애도 | 비인간 존재도 애도한다 |
| 전쟁과 평화의 방패 | 시장·농사·전투를 한 방패에 새김 | 공동체는 전쟁만으로 설명되지 않는다 |
| 분노한 전사와 강신/자연 반격 | 강을 더럽힌 전사에게 물살이 반격 | 자연도 반대 행위자다 |
| 분노·명예·가족·사절 | 출전 거부, 전리품, 성벽 가족, 반복 사절 | 사적 선택의 공적 비용 |
| 시신·장례·판정·연민 | 제한된 운구와 재경기 | 의례가 적대와 기억을 조정한다 |

## 보상 정본과 호감도 경계

정본 분류는 정확히 스킬, 기연, 칭호, 인물 호감도, 단체 호감도, 아이템·소모품, 퀘스트 아이템, 패물(佩物), 기억 파편이다. 등급은 보통·희귀·전설이며 수치는 provisional이다. 선택 보상은 대체로 일반 배타, 재등장 시 기억 파편 또는 미선택 방향 복기 대사로 전환한다. 인물 호감도와 단체 호감도는 메인 관계가 아니라 이 문서의 로컬 NPC·독립 세력에만 적용한다. 전설은 trade-off를 갖는다. 보상 이름은 정통 무협풍, 서정적 은유, 현대인 시선을 섞는다.
