# 최종장 결산 라우팅 마스터

소유자: 두현 황

# 문서 목적

이 문서는 `사도 최종전 → 보스 결산 → 무명/서하린/청류문/천기록/흑사방 후일담` 전체 흐름을 하나의 결산 라우팅 표로 관리한다.

개별 카드의 본문과 변주는 각 카드에서 관리하고, 이 문서는 다음만 관리한다.

```
1. 어떤 입력값이 최종장 결산에 들어오는가
2. 어떤 결과가 우선 판정되는가
3. 어떤 후일담 카드가 출력/강화/억제되는가
4. 중복 카드와 suppress 충돌은 어떻게 해결하는가
5. 입력값 이름은 무엇을 canonical로 쓸 것인가
```

# Single Source 운영 원칙

```yaml
single_source_of_truth_policy:
  owns_final_routing:
    - final_result_priority
    - final_epilogue_master_matrix
    - final_conflict_rules
    - audit_findings
  referenced_by:
    - "보스 결산"
    - "무명 결산"
    - "08. 엔딩과 후일담 연결"
    - "사도 최종전 1/2/3페이즈 카드"
  update_rule:
    - "결과 우선순위, 후일담 enable/suppress, 상호 배타 충돌은 이 문서에서 먼저 수정한다."
    - "개별 사건/후일담 카드는 자기 축의 의미, 대사, 변주, 아이템 해석을 관리한다."
    - "개별 카드에 별도 전체 라우팅 매트릭스를 복제하지 않는다."
  allowed_local_summary:
    - "개별 카드에는 대표 출력 경향과 톤 메모만 둔다."
    - "local summary는 마스터와 충돌하면 마스터를 따른다."
```

# Canonical 입력값 사전

아래 이름을 최종장 라우팅의 canonical key로 사용한다.

```yaml
canonical_final_inputs:
  combat_result:
    values:
      - battle_loss
      - battle_victory
    notes:
      - '전투 승패만 나타낸다. 의미 있는 승리 여부는 별도 결과키에서 판정한다.'

  network_handling:
    values:
      - ignored
      - partially_destroyed
      - ledger_secured
      - core_network_cut
    notes:
      - '장부/조직망 처리 상태. 흑사방 잔향 카드와 무림맹 증거 판정에 직접 사용한다.'

  evidence_state:
    values:
      - none_or_low
      - partial
      - strong
    notes:
      - '검은 비늘 장부 조각은 partial, 최종전 장부 확보와 제출 가능 증거는 strong 후보.'

  pressure_state:
    values:
      - unresolved
      - eased
    notes:
      - '인질성 압박, 장터/표국 압박, 후원자 압박의 해소 여부.'

  seoharin_axis:
    values:
      - low
      - high
      - distorted_high
    notes:
      - 'distorted_high는 관계축은 강하지만 보호가 소유/통제로 뒤틀린 침식 변주에만 쓴다.'

  qingliu_rebuild:
    values:
      - low
      - partial
      - high
    notes:
      - '청류문의 생존이 아니라 재건 조건과 압박 해소 정도를 나타낸다.'

  mumyeong_salvation:
    values:
      - low
      - partial
      - substantial
    notes:
      - '청류문 복귀 여부만 보지 않는다. 자기 흐름, 후계 구도 억제, 진실 처리 방식을 함께 본다.'

  successor_route:
    values:
      - active
      - weakened
      - suppressed
    notes:
      - '사도식 계산법이 무명에게 남는 정도.'

  own_flow_choice:
    values:
      - not_opened
      - opened_but_unresolved
      - chosen
    notes:
      - '무명이 남의 흐름을 훔치는 방식에서 벗어났는지 나타낸다.'

  truth_state:
    values:
      - unknown
      - partial_truth_known
      - truth_known_and_not_forced
    notes:
      - '무명 관련 진실을 얼마나 알았고, 강요 없이 처리했는지 나타낸다. evidence_state와 혼동하지 않는다.'

  cheongirok_state:
    values:
      - low_use
      - high_use
      - corruption_high
    notes:
      - '천기록 사용량과 침식/심마 위험. high_use와 corruption_high를 혼동하지 않는다.'

  player_method:
    values:
      - outside_calculation
      - protected_as_person
      - direct_boss_focus
      - used_as_tool
      - sado_style_calculation
    notes:
      - '플레이어가 사람/관계/증거를 어떤 방식으로 처리했는가. 침식 승리와 후일담 suppress의 핵심 입력값.'

  item_logs:
    values:
```

# 최종 결과 우선순위

```yaml
final_result_priority:
  1_battle_loss:
    if:
      combat_result: battle_loss
    result_key: battle_loss
    reason: '패배는 다른 승리 조건보다 먼저 처리한다.'

  2_corrupted_victory:
    if:
      combat_result: battle_victory
      cheongirok_state: corruption_high
      player_method: sado_style_calculation
    result_key: corrupted_victory
    reason: '관계/증거 조건이 높아도 사도식 계산으로 이기면 침식 승리가 우선한다.'

  3_true_route_victory:
    if:
      combat_result: battle_victory
      seoharin_axis: high
      mumyeong_salvation: substantial
      qingliu_rebuild:
        - partial
        - high
      item_logs_contains: item_unpriced_wooden_sword
      cheongirok_state:
        not: corruption_high
    result_key: true_route_victory
    reason: '소속/뜻/무명/목검 조건이 모두 살아 있을 때만 진엔딩 계열 승리로 판정한다.'

  4_mumyeong_unsaved_victory:
    if:
      combat_result: battle_victory
      mumyeong_salvation: low
      successor_route: active
    result_key: mumyeong_unsaved_victory
    reason: '사도 개인의 패배와 무명의 비구원은 별도로 출력한다.'

  5_meaningful_victory:
    if:
      combat_result: battle_victory
      network_handling:
        - ledger_secured
        - core_network_cut
      evidence_state: strong
      cheongirok_state:
        not: corruption_high
    result_key: meaningful_victory
    reason: '사도 개인뿐 아니라 사도식 조직 원리 일부를 실제로 흔든 승리다.'

  6_incomplete_victory:
    if:
      combat_result: battle_victory
      any:
        - network_handling: partially_destroyed
        - evidence_state: partial
    result_key: incomplete_victory
    reason: '압박은 줄었지만 증거/조직망 처리에 손실이 남는다.'

  7_basic_victory:
    if:
      combat_result: battle_victory
    result_key: basic_victory
    reason: '다른 조건이 없으면 사도 개인 격파 중심의 기본 승리로 처리한다.'
```

```
천기록은 정답지가 아니며, 사도를 이기는 치트로 쓰지 않는다.
```
