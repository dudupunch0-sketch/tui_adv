# 02. 주요 등장인물

소유자: 두현 황

# 핵심 인물 후보

```
1. 주인공
2. 서하린
3. 청류문 장문인
4. 무명
5. 흑사방 보스
6. 무림맹 감찰관 또는 사자
7. 객잔 주인 / 정보상
8. 천기록 관련 존재
```

실제로 플레이어와 자주 부딪히는 인물은 4~5명 정도로 제한한다.

```
무명 = 라이벌 슬롯
흑사방 보스 = 숙적 / 최종 보스 슬롯
흑사방 말단과 기타 적수 = 사건 카드에서만 보조적으로 사용
```

# 핵심 인물 감정 슬롯

```
서하린 = 소속감 슬롯
- 친화적이지 않지만 소속감을 필요로 하는 인물
- 청류문의 감정적 얼굴
- 주인공과 무명을 통해 “돌아올 수 있는 자리”라는 테마를 담당한다

무명 = 정체성 슬롯
- 남의 흐름을 훔치는 자인가, 자기 흐름을 찾는 자인가

흑사방 보스 = 힘 / 통제 슬롯
- 표시명: 흑사방주 사도
- 사도는 본명이 아니라 별호다
- 본명은 끝까지 밝혀지지 않는다
- 사도라는 호칭은 蛇道 / 邪道 / 蛇屠 등으로 풍문처럼 흔들릴 수 있다
- 약점과 욕망을 조직의 자산으로 바꾸는 인물

무림맹 감찰관 = 절차 / 책임 회피 슬롯
- 이름을 붙이지 않는다
- `무림맹 감찰관`이라는 직책 그대로 등장한다
- 공문, 감찰, 절차, 책임 회피의 얼굴로 사용한다
- 비중은 낮게 유지한다

청류문 장문인 = 뜻 슬롯
- 굽히지 않는 뜻과 흐르는 방식의 차이를 남기는 인물
```
