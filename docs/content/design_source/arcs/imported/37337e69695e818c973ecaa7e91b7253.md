# 문서 목적

이 문서는 `이구학지 — 천기록`의 초반-중반-후반을 하나의 큰 방향으로 잇는 true ending 단일 루트를 정의한다.

현재 단계의 목표는 여러 분기를 동시에 확장하는 것이 아니다. 먼저 플레이어가 왜 흑사방과 엮이고, 왜 사도 최종전까지 가야 하며, true ending이 어떤 선택의 누적으로 성립하는지를 하나의 기준선 진행으로 확정한다.

여기서 `단일 루트`는 최종 게임이 하나의 루트만 가진다는 뜻이 아니다. 한 번에 모든 루트를 설계하면 핵심 spine이 흐려지므로, 먼저 true ending으로 이어지는 기준선을 세우고 이후 초반/중반/후반의 각 지점에 브랜치, 실패 변주, 침식 변주, 귀환/정착 변주를 끼워 넣기 위한 설계 순서를 뜻한다.

비목표:

- 귀환/정착/장악/침식 분기 확장
- 수치형 전투 밸런스 확정
- 모든 사건 카드 DB 행 일괄 수정

# 한 줄 방향

```
흑사방은 주인공이 쓰러뜨릴 첫 악당이 아니라,
청류문과 장터의 약점을 가격표로 바꾸는 구조다.

true ending은 그 구조를 힘으로만 부수는 것이 아니라,
가격을 매길 수 없는 관계와 뜻을 끝까지 남기는 길이다.
```

메인 루트 문서의 최종 답은 다음 문장이다.

```
뜻을 지키기 위해 힘을 얻는다.
하지만 힘을 얻기 위해 뜻을 팔지는 않는다.
```

이 true route는 이 문장을 초반부터 최종장까지 반복해서 검증한다.

# 왜 흑사방과 엮이는가

## 표면 이유

주인공은 장터에 떨어진 직후 흑사방 말단과 부딪힌다.

표면적으로는 단순하다.

- 낯선 복식의 외지인
- 무공을 모르는 듯한 사람
- 목에 이상한 패를 건 사람
- 통행세와 보호세를 뜯기 좋은 대상
- 주변에 바로 편을 들어줄 문파가 없는 사람

흑사방 말단은 주인공을 강한 적으로 보지 않는다. 돈이 될지 모르는 물건, 겁주면 굴복할 외지인, 장터에서 본보기로 삼기 좋은 사람으로 본다.

## 구조 이유

흑사방은 장터 깡패 조직이 아니다. 이 route에서 흑사방의 본질은 다음이다.

```
폭력 조직이 아니라 약점 회계 조직.
```

흑사방은 사람을 직접 죽이기보다 다음을 장부화한다.

- 빚
- 치료비
- 보호세
- 통행권
- 후원서
- 표국 운송권
- 가족과 문파의 약점
- 정파가 외면한 사건
- 갚을 수 없는 은혜

주인공이 청류문에 들어간 뒤에도 흑사방과 끊어지지 않는 이유는, 청류문 자체가 이미 흑사방의 장부 안에 있기 때문이다.

## 인물 이유

서하린이 주인공을 구하면서 일이 커진다.

서하린의 개입은 선행이지만, 흑사방의 관점에서는 장부 질서를 깨는 행동이다. 흑사방은 이렇게 본다.

```
보호세를 내지 않는 몰락 문파가,
돈도 연줄도 없는 외지인을 공짜로 데려갔다.
```

이 순간 주인공은 흑사방에게 단순 피해자가 아니라 청류문을 흔들 수 있는 새 약점이 된다.

## 사도 입장에서의 이유

사도는 주인공을 초반부터 강자로 보지 않는다. 오히려 불쾌한 빈칸으로 본다.

사도가 주목하는 이유:

- 주인공은 이 세계의 기존 빚과 서열 밖에서 왔다.
- 주인공은 관계를 손익보다 먼저 선택하는 순간이 있다.
- 주인공은 장부를 단순 문서가 아니라 구조로 읽을 수 있다.
- 천기록은 사도의 계산법을 이길 도구가 아니라, 닮아갈 위험을 가진 거울이다.

따라서 사도는 주인공을 죽이기보다 먼저 가격을 매기려 한다. 어떤 사람을 흔들면 움직이는지, 무엇을 지키려 하는지, 어느 정도의 빚을 지면 뜻을 파는지를 보려 한다.

# 초반: 가격표가 붙기 전

## 핵심 질문

```
이 세계에서 힘없는 사람은 바로 가격표가 붙는가?
```

초반의 흑사방은 무서운 보스가 아니라 매우 일상적인 압박으로 나타난다.

- 통행세
- 보호세
- 치료비 협박
- 시장 상인의 침묵
- 정파의 늦은 개입
- 청류문의 애매한 권위

주인공은 첫 사건에서 흑사방과 싸워서 이기는 사람이 아니다. 오히려 이 세계에서 약자가 어떻게 계산당하는지를 몸으로 배운다.

## 초반 사건 spine

```
낯선 장터에 떨어지다
↓
흑사방 첫 시비
↓
서하린의 개입
↓
청류문 임시 수습생 등록
↓
청류안 첫 발현
↓
흑사방의 청류문 압박
```

## 초반의 핵심 전환

처음에는 흑사방이 주인공을 노린다. 하지만 곧 주인공은 흑사방이 이미 청류문과 장터를 노리고 있었다는 사실을 알게 된다.

전환 장면:

```
주인공은 자신이 맞은 이유를 묻다가,
서하린이 왜 곧바로 흑사방 이름을 알아들었는지 깨닫는다.

그들은 오늘 처음 나타난 위험이 아니었다.
```

## 초반 선택의 true route 기준

좋은 선택은 무조건 용감하게 덤비는 것이 아니다.

true route에 맞는 선택:

- 장터 상인을 탓하지 않는다.
- 서하린을 소유하거나 구원 대상으로 보지 않는다.
- 청류문에 보호받는 대가를 인정하되, 자신을 팔아 갚으려 하지 않는다.
- 흑사방 말단을 죽이거나 모욕해서 압박을 키우지 않는다.
- 작은 기록을 남긴다. 누가 누구에게 얼마를 요구했는지 본다.

초반 state seed:

```yaml
early_route_state_seeds:
  pressure_state: "unresolved_but_seen"
  seoharin_axis: "trust_seed"
  qingliu_rebuild: "debt_seen"
  evidence_state: "rumor_and_receipt_seed"
  player_method: "does_not_sell_self_or_others"
```

# 중반: 흑사방은 장부다

## 핵심 질문

```
폭력을 이기는 것과 구조를 끊는 것은 같은 일인가?
```

중반부터 흑사방은 물리적 적보다 장부와 조직망으로 더 많이 등장한다.

- 후원서가 접힌 채 보관되어 있다.
- 표국이 청류문 물자를 늦게 보낸다.
- 장터 사람들은 증언을 꺼린다.
- 정파 문파 하나가 사라졌는데, 기록에는 단순 사고처럼 적힌다.
- 무명은 남의 흐름을 훔쳐 살아남는 방식으로 밀려난다.

이 구간의 목적은 흑사방을 때려잡을 대상에서 읽어내야 할 구조로 바꾸는 것이다.

## 중반 사건 spine

```
무명 첫 목격
↓
흑사방의 청류문 압박 심화
↓
접힌 청류문 후원서 발견
↓
정파 문파 멸문 단서
↓
무명 중반 재회
↓
무명의 정파 무공 간파
↓
무명의 카피 무공 공개
↓
무명 이탈의 진실 정리
```

## 무명의 역할

무명은 중반의 선택지를 단순히 어렵게 만드는 라이벌이 아니다. 무명은 사도의 계산법이 사람에게 남으면 어떤 형태가 되는지 보여주는 인물이다.

무명의 핵심은 다음이다.

```
훔친 초식은 재능의 문제가 아니라,
자기 흐름을 가질 기회를 빼앗긴 사람이 택한 생존법이다.
```

true route에서 플레이어는 무명을 사도 공략용 도구로 쓰지 않는다. 무명을 설득하거나 폭로해서 약화시키는 것이 아니라, 무명이 자기 흐름을 선택할 수 있는 조건을 남긴다.

## 중반의 증거 축

중반에서 증거는 보스전을 쉽게 만드는 열쇠가 아니다. 후일담에서 흑사방 조직망과 무림맹 책임 회피를 다루기 위한 기반이다.

중반 증거 후보:

- 접힌 청류문 후원서
- 주인 없는 정파 패
- 보호세 요구 기록
- 표국 지연 기록
- 정파 문파 멸문 관련 모순 기록
- 무명이 익힌 정파 초식의 출처 단서

중반 state updates:

```yaml
mid_route_state_updates:
  evidence_state: "partial_to_strong_candidate"
  network_handling: "supply_and_sponsor_web_seen"
  qingliu_rebuild: "practical_rebuild_started"
  mumyeong_salvation: "truth_access_opened"
  seoharin_axis: "belonging_understood_as_place"
```

# 후반: 사도는 가격을 묻는다

## 핵심 질문

```
무엇을 지키려 하는지 알면, 그것은 약점인가?
```

후반의 흑사방은 사도로 수렴한다. 사도는 강한 무공만 가진 보스가 아니라, 지금까지 쌓인 모든 관계와 증거를 가격표로 바꾸려는 인물이다.

사도의 후반 압박:

- 청류문을 지키려면 증거를 포기하라고 한다.
- 무명을 구하려면 장부를 놓으라고 한다.
- 서하린의 기다림을 약점으로 부른다.
- 천기록의 강한 문장으로 빠른 해결을 유혹한다.
- 장터 사람들의 침묵을 책임 회피로 돌린다.

## 후반 사건 spine

```
보스 첫 등장
↓
흑사방 보스의 스카웃
↓
무너져가는 청류문 습격
↓
사도 관련 사건 카드 확인
  - 주인 없는 정파 패
  - 사도의 낡은 장갑
  - 사도의 붓
  - 값이 매겨지지 않은 목검
↓
사도 아이템 로그 결산
  - 검은 비늘 장부
  - 접힌 청류문 후원서
  - 값이 매겨지지 않은 목검
↓
사도 최종전 진입
```

## 스카웃 장면의 의미

흑사방 보스의 스카웃은 악의 유혹 장면이 아니다. 사도식 세계관을 플레이어에게 가장 합리적으로 설명하는 장면이다.

사도의 제안은 이렇게 들려야 한다.

```
네가 지키려는 것들은 이미 값이 매겨져 있다.
그 값을 모르는 척하느라 네가 더 많은 사람을 다치게 할 뿐이다.
```

true route에서 플레이어는 이 제안을 감정적으로 거부하는 데서 끝나지 않는다. 장부와 조직망을 확보해서 사도의 말이 왜 그럴듯했는지, 그리고 왜 틀렸는지를 동시에 증명해야 한다.

후반 state updates:

```yaml
late_route_state_updates:
  evidence_state: "strong_candidate"
  network_handling: "core_block_candidate"
  pressure_state: "partially_eased"
  mumyeong_salvation: "own_flow_choice_prepared"
  cheongirok_state: "danger_seen_but_restrained"
  player_method: "refuses_sado_style_calculation"
```

# 최종장 연결

이 route의 최종장은 이미 작성된 `사도 최종전` 페이즈를 사용한다. 새로 수치형 전투를 만들지 않는다.

true route 기준에서 각 페이즈의 의미는 다음이다.

## 1페이즈: 가격표

핵심은 사도에게 빨리 닿는 것이 아니라 장부고에 쌓인 사도의 계산법을 어떻게 처리했는가이다.

true route 선택:

- 장부를 확보한다.
- 인질성 압박을 일부 해소한다.
- 증거를 태우거나 방치하지 않는다.

## 2페이즈: 약점 장악

핵심은 사도가 관계를 약점으로 읽는 방식에 어떻게 대응하는가이다.

true route 선택:

- 서하린 관련 압박에 대응한다.
- 무명에게 흐름을 돌려준다.
- 천기록의 위험한 문장을 읽더라도 계산 장치처럼 쓰지 않는다.

## 3페이즈: 계산식 밖

핵심은 사도를 약화시키는 것이 아니라, 사도식 계산 밖에서 남는 것들을 실제로 보여주는 것이다.

true route 선택:

- 비워둔 자리를 떠올린다.
- 무명에게 자기 흐름을 선택하게 한다.
- 청류문의 뜻으로 버틴다.
- 장부의 빈칸을 지적한다.
- 사도식 계산으로 맞서지 않는다.

# True Ending 감정선

true ending은 “완벽한 승리”가 아니다.

남는 것:

- 청류문은 완전히 회복되지 않았지만 다시 흐를 수 있다.
- 서하린은 누군가를 붙잡는 대신 돌아올 자리를 남긴다.
- 무명은 청류문으로 완전히 돌아오지 않더라도 남의 흐름을 훔치는 방식에서 벗어날 가능성을 얻는다.
- 흑사방은 사라지지 않지만 사도의 장부와 핵심 조직망은 흔들린다.
- 천기록은 답을 준 것이 아니라, 답을 계산하려는 유혹을 보여준 장치로 남는다.

핵심 후일담 출력 후보:

```yaml
true_route_epilogue_outputs:
  main:
    - "부러진 검은 뱀"
    - "무림맹의 침묵"
    - "청류문의 후일"
    - "복구된 무공의 후일"
    - "서하린의 후일"
    - "비워둔 자리"
    - "문밖의 두 번째 목검"
    - "훔친 초식이 멈춘 날"
    - "닫히지 않은 산문"
    - "천기록의 마지막 장"
  suppress:
    - "흑사방의 깃발"
    - "검은 뱀의 새 비늘"
    - "닫힌 산문"
```

# 작성 가드레일

## 금지

- 흑사방을 초반 잡몹 조직으로만 처리하지 않는다.
- 사도를 순수 악당 또는 갱생 대상으로 쓰지 않는다.
- 서하린을 구출 대상이나 보상 관계로 만들지 않는다.
- 무명을 보스 공략용 약점 장치로 쓰지 않는다.
- 천기록을 정답 검색기나 전투 치트로 쓰지 않는다.
- true ending을 모든 문제가 해결되는 완전 해피엔딩으로 만들지 않는다.

## 권장

- 초반에는 흑사방의 폭력보다 장터 사람들의 침묵과 빚을 먼저 보여준다.
- 중반에는 흑사방의 무서움이 주먹이 아니라 장부와 연결망임을 드러낸다.
- 후반에는 사도의 말이 일부 맞아 보이게 만든다.
- 최종장에서는 사도를 이기는 것과 사도식 계산법을 넘는 것을 분리한다.
- true ending은 대가 없는 관계가 실제로 남았다는 작은 증거들로 닫는다.
