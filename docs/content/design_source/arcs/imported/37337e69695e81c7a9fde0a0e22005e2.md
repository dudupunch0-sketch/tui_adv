# 사도 최종전 상태값 사전

소유자: 두현 황

# 문서 목적

이 문서는 `사도 최종전 → 보스 결산 → 후일담 출력`에서 사용하는 상태값 이름과 값의 의미를 확정한다.

개별 사건 카드와 후일담 카드는 이 문서를 기준으로 상태값을 생성/소비한다.

```
이 문서는 전투 수치표가 아니다.
상태값은 선택의 대가, 증거 상태, 조직망 처리, 관계축, 천기록 사용 방식, 플레이어의 처리 방식을 후일담으로 전달하기 위한 라우팅 언어다.
```

---

```
사도 최종전
사도 최종전 1페이즈: 가격표
사도 최종전 2페이즈: 약점 장악
사도 최종전 3페이즈: 계산식 밖
보스 결산

최종장 결산 라우팅 마스터
08. 엔딩과 후일담 연결
사도 아이템 로그 DB
10. 이구학지 후일담 카드 DB
11. True Ending 단일 루트: 흑사방과 엮이는 길
12. True Ending 기준선 위 분기 확장 설계
```
