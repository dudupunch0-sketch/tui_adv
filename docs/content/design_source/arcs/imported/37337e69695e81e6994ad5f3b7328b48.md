# 12. True Ending 기준선 위 분기 확장 설계

소유자: 두현 황

# 문서 목적

이 문서는 `11. True Ending 단일 루트`로 확정한 기준선 위에 삽입할 분기 후보를 관리한다.

기준 원칙:

```
true ending 기준선은 최종 게임의 단일 루트가 아니다.
그 기준선은 분기를 꽂기 위한 중심 spine이다.
분기는 기준선을 흐리지 않고, 어느 지점에서 어떤 상태값이 바뀌는지로 설계한다.
```

# 분기 삽입 원칙

```yaml
branch_expansion_policy:
  keep_true_route_spine: true
  branch_definition_rule:
    - "분기는 별도 세계선이 아니라 기준선의 특정 선택/상태값 변화로 삽입한다."
    - "각 분기는 생성 위치, canonical state 변화, 사도 최종전 소비 위치, 후일담 출력/suppress를 가진다."
    - "분기 추가 시 true route 조건을 무너뜨리는지, 변주로 공존 가능한지 먼저 판정한다."
  forbidden:
    - "분기를 새 메인 루트 전체로 처음부터 다시 쓰지 않는다."
    - "침식/장악 분기를 더 강한 보상 루트처럼 쓰지 않는다."
    - "귀환/정착을 단순 해피엔딩/배드엔딩으로 나누지 않는다."
```

# 기준선 단계별 분기 삽입 지점

```yaml
branch_insertion_map:
  early_phase:
    spine:
      - "낯선 장터에 떨어지다"
      - "흑사방 첫 시비"
      - "서하린의 개입"
      - "청류문 임시 수습생 등록"
      - "청류안 첫 발현"
      - "흑사방의 청류문 압박"
    branch_slots:
      return_seed:
        trigger: "현대 복귀 단서에 집착하거나 회사/현대 정체성을 계속 우선"
        state_bias:
          player_method: direct_boss_focus_candidate
          cheongirok_state: high_use_candidate
      settlement_seed:
        trigger: "청류문을 임시 거처가 아니라 돌아올 곳으로 받아들이기 시작"
        state_bias:
          qingliu_rebuild: partial_candidate
          seoharin_axis: high_candidate
      corruption_seed:
        trigger: "청류안/천기록으로 사람의 빈틈을 먼저 보려 함"
        state_bias:
          cheongirok_state: corruption_high_candidate
          player_method: sado_style_calculation_candidate

  middle_phase:
    spine:
      - "무명 첫 목격"
      - "접힌 청류문 후원서"
      - "정파 문파 멸문"
      - "무명 중반 재회"
      - "무명의 정파 무공 간파"
      - "무명의 카피 무공 공개"
      - "무명 이탈의 진실 정리"
    branch_slots:
      mumyeong_unsaved_seed:
        trigger: "무명의 죄를 약점으로 쓰거나 진실을 강요"
        state_bias:
          mumyeong_salvation: low_or_partial_candidate
          successor_route: active_candidate
          player_method: used_as_tool
      orthodox_revenge_seed:
        trigger: "현악문/복호금쇄수 단서를 정파 전체 복수 명분으로 확대"
        state_bias:
          player_method: sado_style_calculation_candidate
          cheongirok_state: high_use_or_corruption_high_candidate
      evidence_loss_seed:
        trigger: "후원서/장부/정파 패를 스캔들 또는 분노 해소 도구로 처리"
        state_bias:
          evidence_state: partial
          network_handling: partially_destroyed

  late_phase:
    spine:
      - "보스 첫 등장"
      - "흑사방 보스의 스카웃"
      - "무너져가는 청류문 습격"
      - "사도 관련 아이템/증거 확인"
      - "사도 최종전 진입"
    branch_slots:
      control_route_seed:
        trigger: "사도의 제안을 논리적으로 받아들이거나 더 효율적인 장부로 맞서려 함"
        state_bias:
          player_method: sado_style_calculation
          cheongirok_state: corruption_high_candidate
      seoharin_distorted_high_seed:
        trigger: "서하린을 지키는 명분이 소유/통제로 뒤틀림"
        state_bias:
          seoharin_axis: distorted_high
          player_method: sado_style_calculation_candidate
      return_or_settlement_lock_seed:
        trigger: "현대로 돌아갈 것인지 강호에 남을 것인지 감정적으로 확정되기 시작"
        context_bias:
          ending_context:
            - return_home_candidate
            - settlement_candidate
        canonical_state_dependency:
          - qingliu_rebuild
          - seoharin_axis
          - player_method
          - cheongirok_state
        note: "return_route/settlement_route는 최종장 canonical state가 아니라 귀환/정착 후일담 문맥으로만 쓴다."

  sado_finale:
    spine:
      - "1페이즈: 가격표"
      - "2페이즈: 약점 장악"
      - "3페이즈: 계산식 밖"
    branch_slots:
      incomplete_victory:
        trigger: "장부 일부 파괴, 증거 손실, 조직망 일부 방치"
        canonical_result: incomplete_victory
      corrupted_victory:
        trigger: "천기록 침식 높음 + 사도식 계산으로 승리"
        canonical_result: corrupted_victory
      mumyeong_unsaved_victory:
        trigger: "무명 구원 낮음 + successor_route active"
        canonical_result: mumyeong_unsaved_victory
      true_route_victory:
        trigger: "증거/관계/무명/청류문/목검 조건 충족 + 사도식 계산을 쓰지 않음"
        canonical_result: true_route_victory
```

# 분기별 설계 초안

## 귀환 분기

```yaml
return_route_branch:
  core_question: "주인공은 현대로 돌아갈 수 있는가, 그리고 무엇을 두고 오는가?"
  should_not_mean:
    - "강호 관계를 실패로 버린다"
    - "청류문이 주인공 없이 망한다"
  true_route_compatible_form:
    condition:
      - qingliu_rebuild:
          - partial
          - high
      - seoharin_axis: high
      - player_method: outside_calculation
    epilogue_bias:
      - epilogue_seoharin_empty_place
      - epilogue_qingliu_future
      - epilogue_tianjilu_last_page_true_route_variant
```

## 정착 분기

```yaml
settlement_route_branch:
  core_question: "주인공은 강호에 남아도 뜻을 팔지 않을 수 있는가?"
  should_not_mean:
    - "현대 정체성 완전 삭제"
    - "청류문 최강화 보상"

    condition:

          - partial

      - epilogue_qingliu_future

```

# 상태값 정규화 메모

분기 문서의 `*_seed`, `*_candidate`, `ending_context`는 최종장 canonical state가 아니다.

```yaml
branch_state_normalization_note:
  event_card_local_values:
    allowed:
      - "*_seed"
      - "*_candidate"
      - "*_seen"
      - "*_trace"
    collapse_before_final_routing: true
  ending_context:
    status: epilogue_context_only
    allowed_use:
      - "귀환/정착/부재/지연 귀환 같은 후일담 표현 문맥"
    forbidden:
      - "final_result_priority의 직접 조건으로 쓰지 않는다."
      - "boss_resolution_route를 대체하지 않는다."
  return_route_and_settlement_route:
    status: branch_label_only
    replace_with:
      - ending_context
      - qingliu_rebuild
      - seoharin_axis
      - player_method
      - cheongirok_state
```


# 다음 작업

1. 귀환/정착 분기는 후일담 문구 후보와 `ending_context` 변주로 확장한다.
2. 침식/장악/무명 비구원/서하린 왜곡 분기는 실제 실패 선택지 문구와 suppress 예시를 추가한다.
3. 새 분기를 추가할 때마다 사건 카드의 local value가 상태값 사전의 canonical state로 접히는지 확인한다.
