# 기억 파편·다회차 보상 운영 (v0.1)

소유자: 두현 황

## 문서 목적

기억 파편을 한 회차의 소비 아이템이 아니라 계정에 귀속되는 다회차 메타 재화로 정의한다.

현재는 경제 수치와 유료 상품 구성을 정하지 않는다. 이름, 획득 감각, 사용 장면, 스토리 보상과의 경계만 설계한다.

## 기본 정의

- 기억 파편은 계정에 귀속된다.
- 플레이를 통해 획득할 수 있다.
- 유료 충전으로 추가 획득하는 방안이 있다.
- 한 번 획득한 보상은 계정 도감에 등록된다.
- 최초 도감 등록 또는 특별한 다회차 발견 시 기억 파편을 지급할 수 있다. 지급량은 추후 경제 설계에서 결정한다.

## 수수께끼 행상인

랜덤 인카운터 수수께끼 행상인을 추가한다.

- 직전 회차에서 플레이어가 실제로 얻었던 아이템 중 일부를 기억 파편으로 구매할 수 있다.
- 행상인은 모든 보상을 항상 판매하지 않는다. 등장 시점·재고·가격·대사는 시드에 따라 변주한다.
- 첫 획득을 행상인 구매로 대체하지 않는다. 행상인은 이미 경험한 보상을 다른 회차에서 보완하는 장치다.
- 메인 스토리의 핵심 진실이나 트루 엔딩 조건을 단순 구매로 대체하지 않는다. 메인 보상은 선택과 사건을 통해 얻어야 한다.
- 사이드·랜덤 보상은 행상인을 통해 회수할 수 있지만, 회수 자체가 같은 사건을 본 경험을 완전히 대체하지는 않는다.

## 다회차 설계 원칙

1. 보상 도감은 플레이어가 다른 선택을 했으면 무엇을 얻었을까를 확인하는 장소다.
2. 직전 회차 보상 회수는 놓친 컨텐츠에 다시 접근할 동기를 주되, 선택의 의미를 무효화하지 않아야 한다.
3. 중복 획득은 단순한 쓰레기 보상으로 만들지 않는다. 기억 파편, 새로운 설명, 변주 대사, 행상인 재고 변화 중 하나로 전환할 수 있다.
4. 기억 파편의 사용처는 행상인 외에도 확장 가능하지만, 전투력·트루 엔딩을 돈으로 직접 구매하는 구조는 별도 검토 없이는 추가하지 않는다.
5. 유료 충전은 플레이로도 획득 가능한 계정 재화라는 점을 명확히 기록하고, 실제 가격·한도·확률·판매 목록은 별도 경제 설계와 검수에서 다룬다.

## 미정이지만 나중에 정할 항목

- 최초 도감 등록 보상량
- 회차 종료 보상량
- 행상인 재고 수와 가격 곡선
- 중복 보상의 전환 우선순위
- 유료 충전의 상품 단위와 구매 제한
- 기억 파편으로 접근 가능한 비전투 편의 기능 목록
