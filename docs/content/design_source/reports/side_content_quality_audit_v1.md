## 3. 정량 사실과 의미 추정

### 기계적 어휘·등급 집계

수정 전 세 문서 전체의 단순 출현 횟수는 공고 41, 목패 6, 사본 26, 봉인 92, 보관 64, 인계 35, 합의 17, 운영안 8이었다. 여덟 어휘 중 하나 이상이 들어간 플레이 단위는 72/86, 83.7%였다. 이는 해당 단어가 항상 나쁘다는 뜻이 아니라, closure 소품이 전체 장면의 언어까지 점유했을 가능성을 찾는 신호다.

Phase 1 편집 뒤 같은 단순 집계는 공고 37, 목패 5, 사본 23, 봉인 75, 보관 60, 인계 30, 합의 15, 운영안 8이며, 하나 이상이 등장하는 단위는 **66/86(76.7%)**다. 감소 방향은 확인되지만 아직 높은 수치이고, 남은 단어가 핵심 해결인지 closure 문장인지는 후속 의미 감사를 거쳐야 한다. 이 수치만으로 반복 문제가 해결됐다고 판정하지 않는다.

수정 전 등급 있는 보상 195개는 보통 64(32.8%), 희귀 121(62.1%), 전설 10(5.1%)이었다. SQ V2는 희귀 44/60(73.3%)로 특히 높았다. 기억 파편은 등급 없는 메타 재화이므로 이 집계에서 일반 희귀도 슬롯처럼 해석하지 않는다.

### 문맥 기반 의미 추정

아래는 문장 의미를 사람이 분류한 추정치다. 경계 사례는 runtime 행동이 없으므로 오차가 있다.

- 행정·custody·운영 설계가 선택의 **핵심 해결**인 단위: 약 57/86(66.3%). 종료 안정점에서만 문서를 쓴 경우는 제외했다.
- 세 선택 모두 큰 손실·거부·대립 없이 온건한 절충인 경우: RI 25/40(62.5%), SQ 32/46(69.6%).
- 명확한 인간 악당이 없는 경우: RI 약 27/40(67.5%), SQ 약 7/10 line. 악당 부재 자체는 결함이 아니며 온건한 선택·낮은 적대 압력과 결합할 때만 피로 요인이다.
- 주 유형이 전투인 RI: 9/40(22.5%). 전투·폭력 행동이 중심인 SQ chapter: 약 4/46(8.7%). 비전투 신체 조작·이동까지 포함하면 RI 약 29/40, SQ 약 25/46이므로 문제는 ‘몸을 전혀 쓰지 않음’보다 ‘적대 압력과 손실이 드묾’에 가깝다.
- 현대 회사원 관점이 명시적으로 선택을 바꾸는 15단위 중 행동으로 재미있게 번역된 사례는 약 6, 요구사항·인수인계·운영 설명에 가까운 사례는 약 9였다.
- SQ 결말 약 9/10은 소유권·운영·기록·배분 모델 선택으로 종결됐다. 특히 SQ V2 5개 c04가 자유로운 운영안 메뉴처럼 읽힐 위험이 있었다.

## 4. 최초 문제와 severity

### P1 — 누적 상태가 gameplay에서 소비되지 않음

SQ V2의 line variable은 주로 선언과 기록에 머물렀고, 후속 선택 가능성·NPC 태도·비용·기본 결말을 충분히 바꾸지 않았다. Iliad SQ01·SQ05도 recap은 있었으나 누적 선택이 최종 장면을 인과적으로 만드는 규칙이 약했다. 영향은 재플레이 변별력 저하, 선택의 가짜성, runtime handoff 모호성이다.

### P1 — 행정적 safe closure가 핵심 gameplay로 비대화

안전을 위해 필요한 공고·장부·봉인·보관이 장면의 마지막 1~2문장이 아니라 선택의 중심 동사가 됐다. 영향은 감정 열기 감소, 현대 업무 문서 같은 인상, 서로 다른 모티브의 체감 중복이다.

### P1 — Iliad 내부 플레이 동사 중복

- `wuxia_iliad_random_02_public_council_voice`와 `wuxia_iliad_random_11_council_hidden_ledger`: 회의·장부 공개.
- `wuxia_iliad_random_15_fair_measure_replay`, `wuxia_iliad_random_19_funeral_race_false_win`, `wuxia_iliad_side_05_the_fair_funeral_games`: 측정·재판정·공동 시상.
- `wuxia_iliad_random_13_enemy_body_route`, `wuxia_iliad_random_18_escort_the_enemy_dead`, `wuxia_iliad_side_04_return_the_enemy_dead`: 유해 경로·custody.

같은 모티브의 재사용 자체가 아니라, local goal과 플레이 동사·비용·감정 결론까지 같다는 점이 문제였다.

### P1 — 대사 저작 준비도 불균형

RI V2·SQ V2에 비해 Iliad SQ01·SQ05는 NPC가 실제로 원하는 것과 말투가 얇았다. 절차를 설명하는 대사로 빈칸을 메울 가능성이 컸다.

### P2 — 희귀 보상 인플레이션

희귀가 일반 완료 보상처럼 사용돼 특별한 발견·희생·trade-off를 표현하지 못했다. 특히 SQ V2 73.3% 희귀 비율이 컸다.

### P2 — 지배적 절충안과 현대 업무 언어

`wuxia_iliad_random_20_road_of_two_obligations`의 ‘길을 넓혀 둘 다 통과’와 `wuxia_random_v2_01_market_queue_proxy`의 번호표는 다른 선택의 이익을 비용 없이 포함하는 정답처럼 보였다. 현대인 관찰은 좋은 소재였지만 번호표·handoff·운영안이라는 명사로 설명될 때 세계 안 행동의 재미를 약화했다.

## 6. Phase 1 이후에도 남는 검수 쟁점

1. **완성 대사:** 욕망·말투 가이드는 보강했지만 실제 대사 길이, 유머 타이밍, 반복 설명은 저작 후 다시 읽어야 한다.
2. **변수 조합 폭발:** 소비표는 authoring 계약이다. runtime schema에서 각 값 조합을 모두 별도 분기로 만들지, 태도·비용 modifier로 압축할지는 handoff 설계가 필요하다.
3. **earned ending 표현:** 기본 결말과 override가 문서상 구별돼도 UI가 세 선택을 같은 무게의 메뉴로 표시하면 의도가 사라진다. 기본 결과·override 비용을 선택문 앞에서 보여 줘야 한다.
4. **보상 경제:** 희귀도 의미는 조정했으나 수치와 실제 획득 빈도가 미확정이라 경제 밸런스는 판단할 수 없다.
5. **전투·신체 연출:** 문서에 물성 장면을 넣었지만 resolver와 animation 없이 손맛·난이도·접근성은 추정만 가능하다.
6. **interleaving 피로:** chapter 사이에 main 1장, 다른 SQ, RI 7개를 실제 대사 분량으로 삽입해 감정 회복과 recap 길이를 재검증해야 한다.
7. **Iliad 비수정 항목:** Phase 1은 우선 사례에 집중했다. 다른 RI·SQ에도 행정 어휘와 희귀 보상이 남아 있으므로 기계적 일괄 치환이 아니라 후속 의미 감사를 해야 한다.

## 7. 현재 성숙도 판정

- **아이디어 정본:** 충족. 86단위의 범위와 stable ID, 선택, 안전 종료, 독립성이 정본화돼 있다.
- **대사 저작 가능:** 부분 충족. Phase 1 대상은 욕망·행동·비용이 선명해졌지만 실제 대사와 조합별 반응 검수가 남는다.
- **runtime 구현 가능:** 미충족. 모든 대상은 `authoring_review_required` / `not_implemented`이며, 변수 소비 schema, override UI, 수치, 대사, 연출, 저장·중복 지급 검증이 필요하다.

validator와 구조 테스트는 ID·필드·장간 안전의 증거로만 사용한다. 재미, 감정, 선택 차별성은 대사 저작과 플레이테스트 없이는 PASS로 승격하지 않는다.
