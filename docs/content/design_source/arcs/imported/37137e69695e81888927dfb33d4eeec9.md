# 04. 메인 루트 구조

소유자: 두현 황

# 문서 목적

이 문서는 `이구학지 — 천기록`의 메인 루트 구조를 관리한다.

메인 루트는 최종 선택 하나로 갑자기 정해지지 않는다. 플레이 중 목표 선택, 사건, 동료 관계, 천기록 사용, 청류문 관계, 흑사방 압박에 따라 점차 좁혀진다.

---

# 기본 원칙

```
플레이 초중반:
여러 루트 가능성 존재

중후반:
목표 선택, 사건, 동료 관계, 천기록 사용에 따라 후보 축소

최종장:
현재 회차에서 가능한 2~3개 선택지 제시

최종 선택:
그 안에서 메인 엔딩 확정
```

# 주요 루트 후보

## 귀환 루트

질문:

```
주인공은 현대로 돌아갈 수 있는가?
돌아가며 무엇을 두고 오는가?
청류문은 주인공 없이도 다시 흐를 수 있는가?
```

후일담 연결:

```
청류문의 후일
서하린의 후일
천기록의 빈 장
현대 회사 잔상
```

## 정착 루트

질문:

```
주인공은 강호에 남는가?
청류문은 주인공을 받아들이는가?
청류문은 살아남기 위해 어디까지 바뀔 수 있는가?
```

후일담 연결:

```
청류문 재건
서하린과의 관계
복구된 청류문 무공
주인공의 현대 흔적
```

## 천기록 / 진실 루트

질문:

```
천기록은 무엇인가?
천외편린은 보상인가, 균열인가?
현대지식은 강호를 살리는가, 망가뜨리는가?
```

후일담 연결:

```
천기록의 마지막 장
천외편린이 남긴 풍문
청류문 무공 복구
심마 / 오염 가능성
```

## 세력 / 장악 루트

질문:

```
주인공은 복구된 청류문 무공과 천기록으로 무림 질서를 흔드는가?
청류문은 존경받는가, 두려움의 대상이 되는가?
```

후일담 연결:

```
무림맹 공문
청류문 평판 변화
무공 도둑이라는 풍문
장악의 대가
```

## 침식 / 붕괴 루트

질문:

```
청류안과 천기록이 폭주하는가?
주인공은 모든 약점을 보지만 사람을 보지 못하게 되는가?
```

핵심 문장 후보:

```
초식은 보인다.
빈틈도 보인다.
거짓도 보인다.

사람은 보이지 않는다.
```

# 최종 결산 축

최종 결산은 보스가 중심이다.

무명도 깊게 연관되지만, 최종적으로 플레이어가 넘어야 할 벽은 흑사방 보스가 대표하는 논리다.

```
힘 없이 뜻을 지킬 수 있나?
```

주인공이 후반에 도달해야 할 답:

```
뜻을 지키기 위해 힘을 얻는다.
하지만 힘을 얻기 위해 뜻을 팔지는 않는다.
```

# True Ending 기준선 현황

초반-중반-후반을 하나의 true ending 방향으로 잇는 세부 spine은 아래 문서를 기준으로 한다.

[11. True Ending 단일 루트: 흑사방과 엮이는 길](https://www.notion.so/37337e69695e818c973ecaa7e91b7253)

현재 상태:

```yaml
true_ending_baseline_progress:
  early_phase_cards: completed
  middle_phase_cards: completed
  late_phase_cards: completed
  sado_finale_connection: completed
  final_routing_master_connection: completed
  epilogue_routing_connection: completed
  state_normalization: completed
  branch_expansion: next_after_baseline
```

기준선 요약:

```
초반: 주인공은 흑사방이 약자에게 가격표를 붙이는 방식을 처음 본다.
중반: 흑사방이 장부/후원/정파 모순/무명 상처를 묶는 구조임을 읽는다.
후반: 그 구조의 얼굴인 사도와, 사도의 기록/통제/가격화 증거를 마주한다.
최종전: 증거와 관계를 모두 들고 사도식 계산 밖에서 버틴다.
후일담: 부러진 검은 뱀, 무림맹의 침묵, 청류문/서하린/무명 긍정 변주를 출력하고 후계/침식/닫힌 산문 계열을 억제한다.
```

# 운영 기준

- true ending 기준선은 최종 게임이 단일 루트만 가진다는 뜻이 아니다.
- 먼저 기준선을 확정하고, 귀환/정착/장악/침식/비구원 분기는 이 기준선 위에 삽입한다.
- 흑사방과 엮이는 이유는 `장터 시비`가 아니라 `청류문과 장터의 약점을 장부화한 구조`로 본다.
- true ending은 사도 개인 격파가 아니라 사도식 계산법 밖에서 남는 관계와 뜻을 증명하는 길이다.
- 상태값은 [사도 최종전 상태값 사전](https://www.notion.so/37337e69695e81c7a9fde0a0e22005e2)의 canonical value를 따른다.

# 2026-07-16 repo runtime 해석 보충

- 메인 루트는 별도 route graph나 reputation/debt schema로 실행되지 않는다. 현재 preview runtime은 encounter 조건, 공통 route flags, final-state seed bridge를 이용해 루트를 좁힌다.
- `wuxia_jianghu_pack`은 Web/terminal 기본 storypack이며 office pack은 legacy/parity 경로다. 현재 구현은 arrival부터 midgame/final seed·epilogue consumer까지 확장되어 있지만, 이 페이지의 귀환/정착/장악/침식 분기 표는 여전히 설계 기준선이다.
- `wuxia_sado_final_battle`과 후속 final-state routing은 full combat resolver가 아니라 기존 encounter schema와 Rust GameCore final consumer 범위다. 13번 페이지를 runtime 완료 스냅샷으로 사용한다.
- C1 leveling/insights는 `1d91db2`로 커밋된 preview runtime 계약이지만, 루트 구조 페이지의 설계 분기표 자체를 자동 확정하는 변경으로 간주하지 않는다.
- 전체 사건 spine, 브리지 후보, 플레이 간극 감사는 [16. 전체 스토리 그래프 / 플레이 흐름 감사](16%20%EC%A0%84%EC%B2%B4%20%EC%8A%A4%ED%86%A0%EB%A6%AC%20%EA%B7%B8%EB%9E%98%ED%94%84%20%ED%94%8C%EB%A0%88%EC%9D%B4%20%ED%9D%90%EB%A6%84%20%EA%B0%90%EC%82%AC%2039f37e69695e81f094fcd8260eb60e66.md)에서 관리한다.
