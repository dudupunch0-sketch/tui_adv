# 최신 미결정 항목 모음

아래 목록을 최신 기준으로 본다.

기존 미결정 항목 중 다음은 이미 해소되었다.

```
무명은 서하린의 선배인가, 동기인가, 오래전에 떠난 인물인가?
→ 확정: 무명은 서하린의 사제.

천기록 관련 존재는 인격적 목소리가 있는가, 기록 시스템에 가까운가?
→ 확정: 초반에는 시스템처럼 보이나, 중후반에는 누군가 적고 있다는 느낌이 생긴다. 정체는 끝까지 미공개.

서하린 상세 설계
→ 확정: 핵심 욕망은 소속감, 핵심 공포는 외로움.
→ 방향: 친화적이지 않지만 소속감을 필요로 하는 인물.
→ 구원: 타인을 가두지 않는 소속감.
→ 타락: 닫힌 울타리화.

공동파 계열 속가문파의 실제 이름
→ 확정: 현악문.
→ 공동파 본산이 아니라, 공동파의 이름과 권위를 빌려 지역에서 영향력을 행사하던 외곽 정파 문파.

공동 속가 금쇄수 최종명
→ 확정: 복호금쇄수.
→ 범을 굴복시키듯 상대의 관절, 기혈, 무기 흐름을 눌러 잠그는 정파식 제압술.

흑사방주 사도 확정 여부
→ 확정: 사도는 본명이 아니라 별호.
→ 본명은 끝까지 밝혀지지 않는다.
→ 사도라는 호칭은 蛇道 / 邪道 / 蛇屠 등으로 풍문처럼 흔들릴 수 있다.

무림맹 감찰관의 최종 비중
→ 확정: 이름 없는 직책형 인물.
→ `무림맹 감찰관`이라는 직업/직책 그대로 등장한다.
→ 공문, 감찰, 절차, 책임 회피의 얼굴로 사용한다.

천기록 기록자의 암시 강도
→ 확정: 중간 암시.
→ 중후반부에 실시간으로 한 획씩 쓰이는 것을 발견한다.
→ 글자로 대화하는 이벤트가 있다.
→ 단, 기록자의 정체는 끝까지 명확히 밝히지 않는다.
```

현재 남은 미결정 항목은 다음이다.

```
없음.

현재까지의 최종 미결정 항목은 모두 확정되었다.
추가 미결정 항목이 생기면 이 섹션에 새로 기록한다.
```

주의:

```
현악문, 복호금쇄수, 흑사방주 사도, 무림맹 감찰관, 천기록 기록자 암시 강도는 확정 기준으로 본다.
천기록 기록자의 정체는 끝까지 명확히 밝히지 않는다.
```

# 2026-07-16 repo 역동기화 체크

- 기준 commit은 repo HEAD `11a3e33`이며, C1 콘텐츠 연결은 `1d91db2`로 커밋되고 D2 보고서까지 검증되었다.
- 현재 런타임 검증 범위에는 고정 주인공/6스탯 판정, 체력 0 붕괴 게이트, Story→Choice→Result stage, final epilogue body blocks, Web W1~W4 표면이 포함된다. 별도 전투 resolver, 캐릭터 생성/시작 성향 표, full relation/debt/faction ledger는 아직 열지 않았다.
- 14번 아이템 DB 네 행은 `items.yaml`과 ID·이름·설명·종류·사용 불가 상태가 일치한다. 15번 기연 DB 세 행은 설계 원문으로 유지 중이며 검증된 runtime의 ID·이름·획득 사건이 달라 reconcile 전에는 `구현됨`으로 바꾸지 않는다.
- 09번 사건 DB는 runtime 전체 목록과 일대일 완전 동기화된 상태가 아니다. 기존 설계 행을 runtime과 개별 대조하고, 없는 runtime card는 설계 원문을 임의 생성/확정하지 않는다. 상세 처리 기준은 13번 페이지와 각 사건 카드의 runtime 대조 메모를 따른다.
- 이 체크포인트의 개념 검수와 repo 실행 검증은 서로 다른 층위다. 구현 완료 표시는 generated bundle/parity/test와 기준 commit을 함께 확인한 경우에만 사용한다.
