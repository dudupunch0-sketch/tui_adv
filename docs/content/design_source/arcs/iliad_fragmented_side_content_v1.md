## 설계 경계와 모티브 분석표

모든 항목은 객패귀로와 완전히 독립한 범용 지역·일회 NPC·독립 세력으로 진입한다. 천기록·서하린·청류문·객패귀로·혈월교·흑사방·사도, 메인 플래그와 트루엔딩을 읽거나 쓰지 않는다. 트로이 구도와 원전 고유명은 복제하지 않는다.

## 메인 장간 스케줄·연재 계약

이 문서는 범용 [장간 교차형 사이드 콘텐츠 저작 계약](../contracts/interleaved_side_content_authoring.md)의 **first conforming example**이다. 아래 규칙은 이 사례만 읽어도 저작·검수할 수 있도록 자체 완결 형태로 유지한다.

이 콘텐츠는 메인 스토리의 각 장 사이에 끼어드는 독립 연재물이다. 기본 기대값은 메인 1장이 끝난 뒤 활성 SQ 1~2개의 현재 장과 RI 약 7개를 섞어 재생한 다음 다음 메인 장으로 넘어가는 흐름이다. scheduler는 RI와 SQ의 정확한 순서를 보장하지 않으며, 같은 SQ의 다음 장이 여러 메인 구간 뒤에 배치되는 것도 정상으로 취급한다.

- 활성 SQ: 한 메인 구간에는 서로 다른 SQ 1~2개만 활성화한다. 같은 SQ의 장을 한 구간에 두 번 배치하지 않는다.
- RI 밀도: 한 메인 구간의 기대값은 약 7개다. 플레이 시간, 지역 가용성, 중복 억제에 따라 줄거나 늘 수 있으며 정확한 개수는 완료 조건이 아니다.
- 순서 불확정: RI와 활성 SQ 장은 섞여 등장한다. SQ 장 사이에 여러 RI나 다른 SQ 장이 들어가도 의미가 이어져야 한다.
- 장간 delay: SQ의 다음 장은 인접 메인 구간에 강제하지 않는다. 메인 chapter 수가 바뀌어도 진입 범주와 anchor만으로 재배치할 수 있어야 한다.
- 독립 재진입: 각 SQ 장은 로컬 진행 변수와 durable anchor만 읽는다. 메인 플래그, 메인 인물 관계, 트루엔딩 상태를 진입 조건으로 삼지 않는다.
- 중복: 이미 완료한 SQ 장은 다시 본문을 재생하지 않는다. recap 한 줄이나 기억 파편 안내로 소비하며 다음 미완료 장의 anchor를 유지한다. RI 중복은 해당 RI의 재등장 정책에 따라 짧은 변형 대사나 보상 변형만 허용한다.
- 누락: SQ 장 하나가 scheduler에서 누락되면 다음 장을 앞당기지 않는다. 누락된 장을 다음 가용 구간에 다시 후보로 올린다. 라인 종료 전에는 순서를 건너뛰지 않는다.
- 이탈: 장 도중 이탈하거나 선택을 완료하지 못하면 그 장의 긴급 상황을 안전한 fallback state로 닫는다. 재개 시 장 처음부터 되풀이하지 않고 fallback recap과 남은 local goal부터 시작한다.
- 라인 포기: 플레이어가 SQ를 명시적으로 포기하면 현재 장을 안전하게 종료하고 후속 anchor를 비활성화한다. 지역의 소문·가격·호감도 같은 비긴급 후일 상태만 남는다.

### scheduler 예시

메인 1장 → RI → SQ01 b01 → RI → SQ03 b01 → RI 묶음 → 메인 2장 → RI → SQ01 b02 → 다른 SQ/RI → 메인 3장

위 예시는 순서 계약이 아니다. 같은 SQ의 다음 장을 바로 요구하지 않고, 각 장이 안전한 장소와 오래 남는 약속·편지·기록으로 끝난다는 점만 고정한다.

## 장 완결성 계약

SQ의 모든 beat는 하나의 독립 chapter다. chapter마다 아래 다섯 요소를 본문에 명시한다.

1. 복귀/회상: 이전 장의 핵심 선택과 현재 anchor를 1~2문장으로 되짚는다. 첫 장은 진입 소문이나 의뢰를 회상한다.
2. 해당 장 local goal: 이번 장에서 시작하고 끝낼 목표를 하나 둔다.
3. 긴급성 same-chapter closure: 전투, 추격, 운구 중 위험, 인질, 시간 제한은 이번 장 안에서 해결한다. 결과는 승패와 무관하게 안전 상태로 닫는다.
4. 종료 안정점: 인물과 물건이 머무는 안전한 장소, 부상자 치료, 유해 custody, 완료된 판정 상태를 명시한다.
5. durable next anchor: 지도, 편지, 약속, 소문, 기록, 공고, 안전한 장소에 맡긴 물건처럼 장간 delay에 견디는 연결만 사용한다.

금지 사항은 cliffhanger 전투, 노출된 시신이나 부상자 방치, 즉시 추격 요구, 다음 이벤트가 곧 발생한다는 전제, 부패·소멸하는 필수 단서다. 실패 역시 부상자 치료소 이송, 추격 종료, 봉인 관 안치, 기록 보관 같은 안전한 fallback state로 닫는다. 다음 장은 이전 긴급 상황의 계속이 아니라 그 결과를 확인하는 새 방문이나 후일 소환으로 시작한다.

| 모티브 | 무협 사건 | 의미 |
|---|---|---|
| 제사장/치유자 모욕과 역병 | 약사와 사당지기를 내쫓은 뒤 우물 열병 | 개인 모욕의 공동체 책임 |
| 공개 회의의 불편한 진실 | 조롱받는 하급 서기의 보급 누락 폭로 | 권력은 발언권을 통제한다 |
| 결투 휴전과 제3자 화살 | 결투 직전 암습 화살로 휴전 파기 | 평화는 외부 폭력에도 취약하다 |
| 환대 증표와 불공정 교환 | 선대 패물을 알아본 적수와 손해 보는 흥정 | 환대와 거래는 양가적이다 |
| 결투 뒤 선물 교환 | 적수끼리 검집과 방호패 교환 | 승패와 관계의 경계를 분리한다 |
| 야간 정찰과 포로 윤리 | 정보를 얻은 포로를 처리할지 결정 | 유용한 정보가 비열함을 면죄하지 않는다 |
| 주인을 잃은 말 | 움직이지 않는 역마의 애도 | 비인간 존재도 애도한다 |
| 전쟁과 평화의 방패 | 시장·농사·전투를 한 방패에 새김 | 공동체는 전쟁만으로 설명되지 않는다 |
| 분노한 전사와 강신/자연 반격 | 강을 더럽힌 전사에게 물살이 반격 | 자연도 반대 행위자다 |
| 분노·명예·가족·사절 | 출전 거부, 전리품, 성벽 가족, 반복 사절 | 사적 선택의 공적 비용 |
| 시신·장례·판정·연민 | 제한된 운구와 재경기 | 의례가 적대와 기억을 조정한다 |

## 보상 정본과 호감도 경계

정본 분류는 정확히 스킬, 기연, 칭호, 인물 호감도, 단체 호감도, 아이템·소모품, 퀘스트 아이템, 패물(佩物), 기억 파편이다. 등급은 보통·희귀·전설이며 수치는 provisional이다. 선택 보상은 대체로 일반 배타, 재등장 시 기억 파편 또는 미선택 방향 복기 대사로 전환한다. 인물 호감도와 단체 호감도는 메인 관계가 아니라 이 문서의 로컬 NPC·독립 세력에만 적용한다. 전설은 trade-off를 갖는다. 보상 이름은 정통 무협풍, 서정적 은유, 현대인 시선을 섞는다.

## 독립 랜덤 인카운터 20개

RI는 한 번의 이벤트에서 local goal과 immediate crisis를 모두 끝내는 3선택 독립 장면이다. 지연 결과는 소문·가격·로컬 호감도·비긴급 지역 상태만 바꾼다. SQ chapter나 메인 사건의 필수 단서, 다음 전투·추격·타이머를 RI에 숨기지 않는다. 다른 콘텐츠와 연계되더라도 bonus recap, 대사, 보상 변형만 허용한다.

### 대화형 5개

#### wuxia_iliad_random_01_pestilence_at_the_well
- 제목/유형: 쫓겨난 약사 / 대화형
- 조건: 역참 우물에 열병 소문이 돌 때 1회.
- 상황: 모욕받은 약사가 떠난 뒤 우물 이용자들이 열병 증세를 보인다. 환자 격리와 수원 폐쇄를 이번 장에서 끝내야 한다.
- 선택지: ① 관리의 공개 사과와 약사 복귀 ② 관리 체면을 남긴 채 비공개 치료 계약 ③ 약사와 함께 우물·약방 원인 조사.
- 즉시 결과: ① 환자를 치료소에 들이고 우물을 봉쇄한다 ② 약사를 중립 진료소에 머물게 하고 환자를 이송한다 ③ 오염원을 가려 폐기하고 남은 환자를 치료소에 인계한다. 어느 선택이든 열병의 즉시 확산은 이 장에서 멈춘다.
- 지연 결과: 약재 가격, 역참 약방의 로컬 단체 호감도, 관리의 평판만 달라진다.
- 보상: ① 단체 호감도 역참 약방(희귀) ② 패물(佩物) 약사패(보통) ③ 기연 열병 앞의 사과(희귀). 일반 배타.
- 종료 안정점: 환자는 진료소, 약사는 약방 또는 중립 진료소, 우물은 검사 완료 전까지 봉인 상태다.
- 재등장/후속 허용: 10회 이동 뒤 회복 소문이나 약값 변형만 허용한다. 환자 구조나 치료를 다시 요구하지 않는다.
- 플래그/원전/의미: iliad_local_01_pestilence. Book 1. 치유자를 모욕한 체면이 공동체의 병이 된다.

#### wuxia_iliad_random_02_public_council_voice
- 제목/유형: 웃음 속의 보급 장부 / 대화형
- 조건: 공개 시장 회의가 열릴 때 1회.
- 상황: 하급 서기가 보급 누락을 폭로하지만 원로들이 출신과 말투를 조롱한다.
- 선택지: ① 서기의 발언을 끝까지 보장 ② 원로와 비공개 검증 ③ 주민 증언을 먼저 수집.
- 즉시 결과: ① 회의록에 발언과 반론을 함께 남기고 회의를 폐회한다 ② 중립 서고에서 장부 사본을 봉인한 뒤 검증 일정을 잡는다 ③ 주민 증언을 서명본으로 묶고 서기를 안전한 숙소로 보낸다.
- 지연 결과: 원로·서기의 로컬 평판, 보급품 가격, 회의 소문만 달라진다.
- 보상: ① 칭호 웃음 뒤에 선 자(희귀) ② 퀘스트 아이템 누락 보급 장부(희귀) ③ 인물 호감도 서기 연휘(보통). 배타.
- 종료 안정점: 회의는 끝났고 장부·증언 사본은 중립 서고에 보관된다. 서기는 귀가하거나 숙소에서 보호받는다.
- 재등장/후속 허용: 회의록 낭독이나 보급 가격 변형만 허용한다. SQ와 메인의 필수 증거로 쓰지 않는다.
- 플래그/원전/의미: iliad_local_02_council_voice. Book 2. 조롱은 논박이 아니며 발언권이 진실의 속도를 정한다.

#### wuxia_iliad_random_03_hospitality_token_trade
- 제목/유형: 두 집안의 오래된 패물 / 대화형
- 조건: 국경 객잔에서 선대 패물을 확인할 때 1회.
- 상황: 적수 둘이 환대 증표를 알아보고 칼을 거두지만 교환 가격은 한쪽에 불리하다.
- 선택지: ① 증표를 근거로 교환 무효화 ② 선대의 거래를 존중 ③ 출처만 확인하고 새 가격으로 재협상.
- 즉시 결과: ① 물건을 원주인에게 돌리고 객잔이 휴전을 보증한다 ② 양쪽이 교환증에 서명하고 각자 숙소로 돌아간다 ③ 중립 객주가 새 가격을 적어 거래를 종결한다.
- 지연 결과: 두 집안의 로컬 호감도, 국경 물품 가격, 불공정 거래에 대한 소문만 남는다.
- 보상: ① 패물(佩物) 선대의 매듭패(희귀) ② 인물 호감도 객주 백련(보통) ③ 퀘스트 아이템 환대 교환증(보통). 배타.
- 종료 안정점: 무기는 객잔 창고에 잠시 맡겨지고 두 적수는 서로 다른 객실에서 밤을 보낸 뒤 별도로 출발한다.
- 재등장/후속 허용: 선대 환대의 bonus recap과 상점 가격 변형만 허용한다. 재결투를 요구하지 않는다.
- 플래그/원전/의미: iliad_local_03_guest_gift. Book 6. 환대는 평화를 열지만 거래의 공정까지 보장하지 않는다.

#### wuxia_iliad_random_04_horse_mourns
- 제목/유형: 움직이지 않는 역마 / 대화형

## 독립 서브 퀘스트 라인

모든 SQ는 로컬 변수와 durable anchor만 갱신한다. beat 하나가 플레이 가능한 chapter 하나이며, 다음 beat가 여러 메인 구간 뒤에 와도 복귀 문장과 anchor만으로 재개한다. 한 메인 구간에는 같은 SQ chapter를 두 번 배치하지 않는다.

### wuxia_iliad_side_01_the_price_of_refusal

- NPC/진입: 표국주 하문, 장부관 노경, 역참 아이 연두. 역참에서 하문이 출전을 거부한다는 소문으로 시작한다.
- 권장 메인 장 배치 폭: 초반~중반 진입, 중후반 결산 허용.
- 최소 장간 공백: 인접 메인 구간 연속을 강제하지 않는다. 같은 메인 구간에 다음 chapter를 배치하지 않는다.
- 최대 장간 공백: 장기 지연 허용. 봉인 장부·곡물 인수표·후일 결산 소환장이 남아 있으면 후반에도 재개한다.
