## 목적과 저작 경계

이 문서는 후속 담당자가 대사·연출·수치 초안을 붙일 수 있도록 만든 독립 RI 20개의 상세 authoring blueprint다. 완성 대사, runtime 이벤트, YAML, 전투 resolver, 보상 지급 구현을 포함하지 않는다. 각 RI는 한 번의 호출 안에서 local goal과 immediate crisis를 끝내며, main chapter나 SQ chapter가 바로 뒤따른다는 전제를 두지 않는다.

- 천기록·서하린·청류문·객패귀로·혈월교·흑사방·사도와 관계 플래그를 읽거나 쓰지 않는다.
- 메인 필수 진행, 진엔딩, SQ 필수 단서·인물·보상을 해금하거나 차단하지 않는다.
- 일회 NPC와 독립 소세력, 범용 장터·객잔·표국·약방·나루·산길만 사용한다.
- 지연 결과는 소문, 가격, 로컬 인물·단체 호감도, 비긴급 지역 상태로 제한한다.
- 재등장은 bonus recap, 짧은 대사, 상점·보상 변형만 허용한다. 미결 전투·추격·치료·인질·재난·부패 단서는 남기지 않는다.
- 선택지는 정확히 3개이며 가치, 비용, 플레이 방식이 서로 달라야 한다. 폭력과 비폭력 어느 한쪽도 자동 정답으로 만들지 않는다.
- 보상은 스킬, 기연, 칭호, 인물 호감도, 단체 호감도, 아이템·소모품, 퀘스트 아이템, 패물(佩物), 기억 파편 taxonomy를 따른다. 선택별 보상은 일반 배타다. 기억 파편에는 이름과 희귀도를 붙이지 않는다.
- 모든 보상 효과 수치는 후속 handoff 대상이다. 전설 보상은 이 문서에 trade-off를 함께 적는다.

## Iliad RI20 중복 금지선

신규 20개는 『일리아스』 모티브에 의존하지 않는다. 특히 역병 약사, 공개 회의 장부, 선대 환대 패물, 애도하는 말, 결투 뒤 선물, 휴전 화살, 야간 포로, 강신 홍수, 빌린 갑옷, 성벽 전령, 숨은 장부, 양면 방패, 적 시신 운구, 말 흔적, 경기 측정, 전리품 분배, 깨진 사절 봉인, 장례 호송, 결승 판정, 가족 행렬과 운구 길 충돌을 소재·갈등의 중심으로 반복하지 않는다. 공개/비공개 절차만 고르는 3택, 결투 승패 재판정, 유해 custody 선택, 장부 공개 여부처럼 기존 선택 골격을 이름만 바꿔 재사용하는 것도 금지한다.

## 대화형 4개

#### wuxia_random_v2_01_market_queue_proxy

- 제목: 한 줄에 세 사람
- 주 유형: 대화
- 감정 톤: 생활 유머, 공정함의 양가성
- 적합 지역/시간/재등장 정책: 큰 장터 약재전, 아침 개장 직후. 본문 1회; 이후 번호패 농담과 대기 가격 변형만 허용.
- 상황과 local goal: 귀한 향신약을 파는 가게 앞에서 한 사환이 세 집 몫을 대신 서자 새치기 시비가 난다. 현대 회사원에게는 대리 접수와 줄 관리 실패로 보이지만, 이곳에서는 몸을 세운 시간이 곧 권리다. local goal은 개장 전 혼잡을 끝내고 오늘 물량의 배분 방식을 확정하는 것이다.
- 선택지: ① 번호패를 만들어 한 사람당 한 몫씩 흐름을 재배치한다 ② 사환의 세 자리를 인정하되 뒤 손님에게 한 자리를 공개 매입하게 한다 ③ 기존 관습을 존중하고 자신이 군중의 밀림을 버티며 약자를 보호한다.
- 선택별 즉시 결과: ① 모두가 번호를 받고 가게가 순서대로 판매해 시비가 끝난다 ② 사환과 손님이 값을 합의하고 세 몫의 소유권을 현장에서 정산한다 ③ 관습대로 판매하되 플레이어가 넘어질 사람을 빼내고 마지막 물량까지 질서를 유지한다.
- 공통 immediate crisis closure: 개장 혼잡과 몸싸움은 판매 종료 전에 해소되고, 다친 사람 없이 가게 문이 닫힌다.
- 지연 결과: 번호패 관습의 소문, 향신약 가격, 약재전 상인회의 로컬 호감도만 달라진다.
- 종료 안정점: 손님은 물건 또는 환불전을 들고 흩어지고, 남은 약재는 잠긴 가게 안에 있다.
- 재등장/후속 허용: 번호표를 흉내 낸 목패, 짧은 농담, 가격 할인만 bonus로 허용한다. 어느 main/SQ의 구매 gate도 되지 않는다.
- 보상: ① 패물(佩物) `석 줄 번호패`(보통) — 혼잡한 공간에서 순서를 읽는 감각 ② 인물 호감도 `사환 모길`(보통) — 대리 노동의 값을 인정한 관계 ③ 스킬 `군중 틈새 보법`(희귀) — 밀집 공간에서 약자를 지키며 움직이는 방향. 일반 배타.
- local flags/state 후보: `wuxia_random_v2_01_resolution = numbered | purchased | customary`, `market_queue_reputation = orderly | pragmatic | stalwart`.
- 창작 의도/플레이 질문: 공정함은 모두에게 같은 규칙인가, 이미 지불한 시간의 거래 가능성까지 인정하는가?
- 후속 대사 저작 가이드: 모길은 영리하지만 비굴하지 않고 세 집의 잔심부름을 진짜 노동으로 여긴다. 말투는 빠르고 셈이 정확하다. 세 자리가 사기 아닌 유상 대리였다는 정보와 오늘 물량이 한정됐다는 사실을 반드시 전달한다. 현대식 번호표 제도를 강의하거나 플레이어가 제도를 발명했다고 찬양하는 설명조 표현은 피한다.

#### wuxia_random_v2_02_storyteller_stolen_life

- 제목: 내 이야기를 파는 사람
- 주 유형: 대화
- 감정 톤: 씁쓸함, 생계와 존엄의 타협
- 적합 지역/시간/재등장 정책: 작은 객잔, 저녁 공연 시간. 본문 1회; 이후 고쳐진 공연 제목과 객잔 소문만 허용.
- 상황과 local goal: 설화꾼 노삼은 떠돌이 짐꾼 여비의 실제 실패담을 영웅담으로 바꿔 돈을 번다. 여비는 조롱처럼 들린다며 공연을 막지만 노삼은 그 이야기가 오늘 끼니라고 맞선다. local goal은 관객이 흥분하기 전에 오늘 공연의 소유와 표현 방식을 합의하는 것이다.
- 선택지: ① 여비에게 수익 몫과 수정권을 주고 공연을 계속한다 ② 첫머리에 허구임을 밝히고 인물·장소를 바꾼다 ③ 공연을 중단시키고 노삼의 오늘 식대를 자신이 부담한다.
- 선택별 즉시 결과: ① 두 사람이 몫을 적은 목패에 서명하고 여비가 결말 한 줄을 고친다 ② 노삼이 즉석에서 이름과 실패 원인을 바꾸고 관객에게 허구라 알린다 ③ 관객에게 돈을 돌려주고 객주가 노삼에게 식사와 잠자리를 제공한다.
- 공통 immediate crisis closure: 고성·밀침 없이 공연의 진행 또는 중단이 확정되고, 당사자와 관객이 객잔 안에서 안전하게 정리된다.

## 집계·Authoring 검수

- stable ID: `wuxia_random_v2_01_`부터 `wuxia_random_v2_20_`까지 top-level RI 정확히 20개.
- 주 유형: 대화 4, 전투 4, 탐색 4, 복합 4, 괴이/환상 4.
- 각 RI: 제목, 주 유형, 감정 톤, 적합 지역/시간/재등장 정책, 2~4문장 상황과 단일 local goal, 정확히 3선택, 선택별 즉시 결과, 공통 immediate crisis closure, 지연 결과, 종료 안정점, bonus-only 후속, 선택별 보상 3개, local state, 창작 의도, 후속 대사 가이드 포함.
- 선택 구조: 흐름 재배치, 수익·표현권 조정, 감각 검증, 노동·공연 교환, 보호 우선, 반복 패턴 정지, 지형 기만 해체, 생태 유도, 부재 복원, 격자·체감 탐색, 이동 규칙 관찰, 기억 보존, 공연 완주·중단, 계약 검사, 생계 방어·이전, 공동 경계, 기억 대가, 이름 분담, 자기 재단, 공간 재배치 등 8종 이상.
- 인간 악당 없이 성립 `H` 16개, 전투 없이 최선 해결 `N` 15개, 현대인 관찰 `M` 6개, 명확한 판타지 규칙 `F` 4개.
- 유머 중심 01·06·16, 쓸쓸함 중심 02·04·09. 폭력 선택의 효용과 비용은 05·07·08·15에서 서로 다르게 배치.
- 기억 파편 보상은 사용하지 않았다. 추후 추가 시 `기억 파편(계정 귀속 재화, 수량 미정·등급 없음)` 형식만 허용한다.
- 전설 보상 08·17·19에는 각각 은밀성 저하, 따뜻한 회상 회복 저하, 그림자 은신 보조 상실 trade-off를 명시했다.
- 모든 인물·단체 호감도는 이 문서의 일회 NPC·독립 소세력에 한정한다.
- Iliad RI20의 금지 소재와 ID를 반복하지 않으며, design source 전체 stable ID 중복 검사를 runtime handoff 전에 다시 수행한다.

### 장간 acceptance tests

| 테스트 | 이 문서의 PASS 판정 |
|---|---|
| delay | RI 뒤에 main chapter 1개와 다른 RI 7개가 와도 미결 위기·필수 후속이 없다. |
| reorder | 어느 RI를 먼저 재생해도 다른 RI의 인물·단서·보상을 전제하지 않는다. |
| stop | 각 `종료 안정점`에서 플레이를 끝내도 전투·추격·재난·치료·인질·부패 단서가 남지 않는다. |
| abandonment | 선택 중 이탈 시 현장 관리자가 대피·폐쇄·인계의 가장 보수적 종료로 수렴하며 main 진행을 막지 않는다. |

| duplicate event | 완료 RI 재호출은 bonus 대사·가격·보상 상태 확인만 제공하고 본문 위기와 일회 보상을 반복하지 않는다. |
| no hidden gate | 모든 RI는 main/SQ 필수 단서, 진엔딩 조건, 핵심 세력 관계를 읽거나 쓰지 않는다. |

## 후속 저작 및 runtime handoff 경계

후속 대사 담당자는 각 RI의 NPC 욕망·말투·필수 정보·금지 표현을 지키되 선택 결과와 종료 안정점을 바꾸지 않는다. 완성 대사는 별도 authored source에서 검수하며 이 blueprint에 긴 대사 전문을 역수입하지 않는다. authoring review 전에는 보상 수치, 재등장 확률, 지역 가중치, 전투 난이도, 저장 필드 자료형을 확정하지 않는다.

Runtime handoff 후보는 stable ID, 주 유형, eligibility, 정확히 3개 choice key, 선택별 immediate result, closure state, delayed local state, replay policy, reward mapping, 독립 의존성 선언이다. 현재 `runtime_status: not_implemented`이며 코드·YAML·bundle·메인 route 구현 완료를 선언하지 않는다.
