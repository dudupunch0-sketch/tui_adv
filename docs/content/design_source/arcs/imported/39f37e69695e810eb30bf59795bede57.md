# 현재 런타임에 구현된 시스템 (2026-07-16)

## 스탯과 판정

- 6스탯 고정: **논리 / 공감 / 의지 / 평정 / 인터페이스 / 신체** (전원 초기값 2)
- 판정: **2d6 + 스탯 ≥ 난이도**. 선택지에 **성공 확률이 사전 공개**된다 (정보의 정직성 문법)
- 판정 결과는 선택한 화면에서 **주사위 + 成/敗 도장 연출**로 먼저 보여준 뒤 장면이 전환된다 (행동 결과 비트)
- 초반 청류문/난투 사건 5곳에 판정 배치 (능력치 5종, 난이도 8~10)

## 자원과 생존

- **체력 / 정신력**: 0~100. 체력 0 → **붕괴 게이트**(기사회생: 체력 +40·경험 -10·1회 한정 / 안식: 사망 엔딩). 정신력 30 이하 → 압박 경고 + 콘텐츠 조건으로 선택지 잠금
- **위험(danger)**: 이동·사건으로 누적, 현재는 연출 계층(게이지 색, 전환 강도)만. 콘텐츠 조건 미사용
- **천기(경험)**: 사건 보상으로 누적, 목표 100. 종장/엔딩 개방 조건은 콘텐츠(`min_experience`)가 조립

## 칭호(특성)

- 번들 `traits` 섹션 + 사건 outcome의 `set_trait`으로 교체. 현재 **표시/서사 장치만** (수치 효과 없음)
- 구현된 칭호: 청류문 초학자 등. 이름 앞에 낙관(인장)으로 표시
- Slice 3 WP-S1에서 코어 `CharacterSummary`가 `title_description`을 전달하도록 확장했다. 설명을 펼쳐 보는 Web UI는 WP-W2~W4에서 커밋했다.

## 천기록/천외편린

- 편린 3후보 중 1선택 문법은 **스레드 플래그** 방식으로 구현 (수치 스탯 아님) — 07 문서의 설계와 일치
- 최종장 결산 라우팅, 후일담 카드 18종 renderer contract 구현 완료 (기존 동기화 항목 유지)
- Slice 3의 코어와 이구학지 preview 번들은 선택적 `runtime.leveling`(`thresholds: [30, 75, 120]`)과 `content.insights` 3개, 기존 outcome의 `add_insights` 연결을 포함한다. C1 export·fixture·parity·Rust/Web/WASM 검증은 D2 보고서에 통과로 기록되어 있다. 다만 15번 Notion 설계 행과 runtime 기연 ID/이름/획득 사건이 다르므로, DB 행의 설계 원문 상태 전환은 별도 reconcile 이후로 둔다.

## 이벤트 스테이지 (신규, 2026-07-16)
